# `findings.md` 本命能力审计与交付矩阵

本文档把 `/Users/xiaoguiwk/Downloads/findings.md` 中出现的功能逐项映射到 Interstellar 的真实运行链。优先级标签不作为删减依据；每项能力必须贯通计算、API、产品展示和测试，才可标记为“完成”。目录、类型或占位文案不能算实现。

状态定义：

- **完成**：真实计算已进入快照，前端可选择或查看，并有测试。
- **部分**：已有算法或目录，但缺少数据、设置、快照、展示或测试中的至少一层。
- **缺失**：没有可执行算法。
- **纠错**：原报告对现状或天文对象的判断不正确，按校正后的专业定义交付。

## 7. 完成定义

每一行从“部分/缺失”改为“完成”前，必须同时满足：

1. 使用锁定公式和本地版本化数据，记录来源、版本、内容哈希和成熟度。
2. 同一输入与设置可完全复现；修改会影响计算的设置必须产生新的输入指纹和快照。
3. API 返回结构化事实，前端可选择并展示；不可把开发字典或内部边界提示塞给普通用户。
4. 轮盘、表格、解读和技术导出对同一快照保持一致。
5. 具有单元、契约、金标准/差异和视觉回归中适用的测试。
6. 数据不足时明确阻断，不以占位结果、静默省略或无来源公式伪装完成。
