## 1. 口径

“不比竞品少”按信息维度验收，不按截图行数机械比较：

- 公开且可验证的确定性字段必须计算并展示；
- 来源不明的专有点位、分数或解释必须明确阻塞，不用相似名称冒充；
- 同一事实可以用更专业的结构替代竞品排布，但不能只藏在原始 JSON 中；
- `未知`、`不适用`、`未选择`、`算法未发布`必须分开表达；
- 所有已物化结果必须能从界面、表格或确定性导出中访问。

## 3. 已确认的专业优势

Interstellar 已经超过竞品样本的确定性维度包括：

- 每个相位保留实际角距、精确角度、容许度、强度和入相/出相；
- 每个点位保留天文坐标、距离、速度、来源、精度与适用性；
- 现代与古典事实分层，不合成来源不明的“好运分”；
- 所有计算记录引擎、数据集、规则方案和输入指纹；
- 黄道和 Ayanamsa 是实际重算参数，不是只移动前端标签；
- 未知和未实现能力明确阻塞，不用 `00:00` 或虚构数值补齐。

## 4. 当前发布阻塞项

本命盘从 Alpha 升为可发布专业版本前，至少必须完成：

1. 把全部已计算的结构与古典事实从原始 JSON 改为可筛选、可核对、可解读的中文表格；
2. 完成所有已物化集合到界面/导出的消费清单，不允许“算了但找不到”；
3. 前端接通 JSON/CSV，并为 SVG/PNG/PDF 建立同源 `RenderSpec` 导出；
4. 扩充逐项解读规则库，做到事实、解释、来源、成熟度和反证边界可见；
5. 完成古典界／面可选轮盘图层、极端密集点位避让、相位矩阵筛选和双主题视觉回归夹具；
6. 完成本命全链路、金标准、差异、DST、高纬、无时间、恢复与隐私测试。

固定星本地目录已经解决，JPL DE442、IERS finals2000A与Natural Earth 5.1.2本地源也已就绪；V1全部7项必需数据源可由`/api/v1/datasets`审计版本、许可证、校验和和当前消费状态。它们仍只能在适配器、算法卡、独立差异测试和界面消费同时完成后参与结果并标记相应成熟度。任意小行星、平行/反平行、映点/反映点和更高级古典状态同样不得因“已有数据文件”而伪装为已计算。

## 5. 不以“补齐”为名复制的内容

- 商业软件专有评分、报告文本和不可验证权重；
- 来源不明的虚点、假想星公式或对象身份；
- “升职概率”“婚姻概率”“项目成功率”等没有客观标定的数据；
- 竞品 UI 的视觉复制；
- 未经授权的出生资料或商业人物库。

这些项目必须保持 `research_blocked`、`license_blocked` 或 `not_scientifically_calibrated` 状态，直到获得独立依据。
