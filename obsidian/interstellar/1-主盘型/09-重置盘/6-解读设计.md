# 重置盘 · 解读设计

> 盘型定位：看清旧周期清理、新基线建立与系统性重启过程
> 核心问题：该停止什么、保留什么、先重建什么，怎样避免反复回滚
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

控制台、清理列表、坐标、金字塔、红线、边界轨道、调试回路；强调系统重建

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                  [等级标签]   │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │        [专属视觉图表区]           │ │
│ │   ▓ 数据点   ◯ 状态   → 趋势     │ │
│ │   [交互热区: ▸ 点击查看详情]     │ │
│ └──────────────────────────────────┘ │
│ 数据标签 · 状态 · 时间窗口            │
├──────────────────────────────────────┤
│ 一句话摘要（20—30字）                 │
│ ▸ 展开详细解读                       │
│   [90—140字展开解读，默认收起]        │
│   数据来源: source_ids / rule_id     │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：系统重置进度

- **视觉结构**：系统重启控制台；显示情绪、关系、工作、身份四模块的清理与重建进度
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│  系统重置进度         综合指数 68     │
├──────────────────────────────────────┤
│  主指数 [████████░░░░░░] 68/100       │
│  双层拆解                            │
│    清理方向 [██████░░] 52  ↘ vs上期  │
│    重建方向 [█████████░] 82  ↑ vs上期 │
├──────────────────────────────────────┤
│  四模块进度                          │
│    情绪 [██████████] ✓ 完成           │
│    关系 [██████░░░░] ◐ 进行中         │
│    工作 [████░░░░░░] ◐ 进行中         │
│    身份 [██░░░░░░░░] ○ 未开始          │
├──────────────────────────────────────┤
│  信号Top3: 过度迎合·边界模糊·节奏失衡  │
│  当前阶段: 重建中   主导方向: ↗重建    │
│               ▸ 点击模块→轮盘联动     │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

| 卡片 | 名称 | 回答的问题 | 核心视觉 |
|---|---|---|---|
| A | 重置总控制台 | 当前重置发生在哪一层，进度如何 | 系统重启控制台 |

### 显示顺序

```text
[系统重置进度 — 顶部固定]
A 重置总控制台 → B 旧模式清理表 → C 新基线坐标 → D 重建优先级金字塔 → E 回滚风险地图 → F 关系边界轨道 → G 资源重配棋盘 → H 30/90/180日重建轴 → I 行为回路调试器 → J 重启协议
```

首屏建议显示：顶部指数 + 卡片A + 卡片B；其余卡片向下滚动。

│    ←     │          变化倾向          │
│            ↓                          │
│           内向                        │
├──────────────────────────────────────┤
│  旧→新: 外向+变化 → 内向+稳定        │
│  旧坐标 (7,8) → 新坐标 (3,4)         │
│  稳定 62%  变化 38%   内向 70%       │

│        ▸ 点击基线点→轮盘联动         │

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 你的新基线正在从【旧坐标】移动到【新坐标】。 |
| 展开解读 | 说明重置不是回到原点，而是建立新的稳定位置。 |

### 展开解读示例

> 旧基线偏向外向变化，容易靠外部反馈维持节奏；新基线移动到稳定与内向交界，更强调自我判断和可持续秩序。

### 交互与动效

- 旧点淡出、新点移动；拖动仅查看含义。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 基线主题、关系/事业/资源权重。

## 十七、信号评分

```text
reset_score = obsolete_pattern × structural_conflict × trigger_density × rebuild_readiness × stability
```

分数只用于排序、指数和视觉强度，不表示事件发生概率。

## 十八、折叠与交互规则

- iOS默认纵向卡片流，所有卡片标题和摘要可见。
- 图表高度建议180—240pt；复杂时间轴可横向滑动，但不得隐藏核心摘要。
- 展开解读默认收起；用户展开后保持本次会话状态。
- 不使用悬停信息，所有关键含义必须通过点击、标签或图例可见。
- 动效只用于表达状态变化，不做装饰性高频闪烁。

## 十九、空状态与降级规则

- 缺少本命数据：隐藏需要本命联动的卡片，并提示补充出生信息。
- 缺少地点：宫位相关图表降级为行星/相位主题，不伪造宫位结论。
- 无高强度信号：保持完整卡片，但显示“低活跃/背景期”，不制造事件。
- 数据不足时：图表显示灰色占位和原因，不用随机分数填充。

## 二十、边界说明

- 所有指数表示主题密度、结构清晰度或体感强度，不表示事件概率。
- 不输出“必然发生”“一定成功”“必定分手”等确定性语言。
- 压力项必须给出调节出口；支持项不得写成结果保证。
- 所有卡片应能追溯到 source_ids、rule_id 和 corpus_id。

## 二十一、验收标准

- 顶部固定指数、10张卡片、摘要、展开解读、视觉示意全部齐全。
- 每张卡片的视觉结构与盘型定位一致，不能套用同一雷达图或同一时间线。
- 每张卡片至少包含4个视觉元素、1个视觉示意、1条摘要模板、1段展开示例。
- 卡片之间回答的问题不重复，首屏能直接看懂当前主线。
- 图表颜色、状态、图例、空状态和交互均有明确规则。
