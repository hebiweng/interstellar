# 日弧盘 · 解读设计

> 盘型定位：看清数年尺度的人生推进、结构性转折与关键发展年份
> 核心问题：正在跨越什么长期阶段，哪些轴线被点亮，关键年份如何形成一段完整的成长过程
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

长弧、塔、蓝图、板块、跑道、里程碑；强调长期结构和身份升级

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                              │
│ [专属视觉图表]                        │
│ 数据标签 / 状态 / 时间窗口            │
│ ────────────────────────────────── │
│ 一句话摘要（20—30字）                 │
│ 展开详细解读 ▸                        │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：结构转折指数

- **视觉结构**：长弧桥 + 当前年龄定位；显示转折清晰度、结构压力、角色升级和落地程度
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ 结构转折指数            68/100 ▲+12 │
│ ██████████████░░░░░░░░░░░░   活跃   │
│ ┌────────────┐  ┌────────────┐      │
│ │结构清晰度  │  │角色升级度  │      │
│ │  72  ▲     │  │  64  ●     │      │
│ └────────────┘  └────────────┘      │
│ 旧阶段 ●═══════╮   ◆① ◆② ◆③ 里程  │
│            ╰══════● 新阶段          │
│ 信号①轴线共振 ②角色迁移 ③结构重建  │
│ ◦ 点击信号→查看底层来源              │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：长期发展总览

### 目标

这轮日弧把人生推向怎样的新阶段。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 旧阶段 | 正在离开的结构 |
| 跨越弧 | 转变过程 |
| 新阶段 | 新身份/新位置 |
| 当前点 | 位于弧线何处 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ 长弧跨越桥            跨越进度 45%    │
│                                      │
│ 旧阶段          跨越弧         新阶段│
│ "任务执行者" ●══════╮  "自主决策者" │
│              ╰══════● 当前点         │
│ ←已完成─┤├─跨越中─┤├─待落地→      │
│              ▲                       │
│         点击弧桥→联动轮盘            │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 你正从【旧定位】跨向【新定位】。 |
| 展开解读 | 说明日弧不是单点事件，而是一段数年结构迁移；解释当前处于预热、跨越还是落地。 |

### 展开解读示例

> 你正在从“完成别人交付的任务”跨向“建立自己的判断和位置”。当前位于跨越中段，旧结构尚未完全退出，新角色已经开始要求你承担更多。

### 交互与动效

- 弧桥随滚动延展；当前点发光。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 日弧太阳、四轴、个人行星、精确度、年龄。

| 预热期 | 主题逐步出现 |
| 精确区 | 最集中阶段 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ 精确触发窗口       核心窗口 ±12个月  │
│                                      │
│  预热期    │█精确区█│    落地区      │
│ ░░░░░░░░░░│████████│░░░░░░░░░░░    │
│ 2026.7    │ 2027.4 │    2028.6      │
│ 主题渐进  │集中触发│    结构成型     │
│           ▲脉冲     ▲                │
│ ◦ 拖动查看年份│点击区段→联动          │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 【年份/月份】前后是这轮日弧的核心窗口。 |
| 展开解读 | 解释长期盘的精确点前后通常有较宽影响，不应只盯一天。 |

### 展开解读示例

> 2027年4月前后是核心窗口，但真正过程从2026年下半年已开始，可能持续到2028年。精确区更像主题被推到台前，而不是事情突然从零发生。

### 交互与动效

- 精确区脉冲发光；拖动查看年份。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 日弧精确日期、容许度、触发等级。

## 9、卡片G：生活板块位移

### 视觉元素

### 视觉示意

```text
┌──────────────────────────────────────┐
│ 生活板块位移      断层:事业↔家庭     │
│                                      │
│ ┌家庭板块┐⇠       ⇢┌关系板块┐      │

│ └───┬────┘       └────┬───┘         │
```
