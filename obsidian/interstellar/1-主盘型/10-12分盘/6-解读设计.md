# 12分盘 · 解读设计

> 盘型定位：看清本命特质下更细的性格底纹、隐性驱动力与关系投射
> 核心问题：表层性格下面还藏着什么细分结构，压力下会启动什么模式，哪些隐性能力被低估
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

拼图、频谱、混色、链条、镜像、折扇、暗纹、格栅；强调人格微观切片

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                              │
│ [专属视觉图表]                        │
│ 数据标签 / 状态 / 时间窗口            │
│ ────────────────────────────────── │
│ 一句话摘要（20—30字）                 │
│ 展开详细解读 ▸                        │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：人格细分密度

- **视觉结构**：人格拼图 + 动机频谱；显示底层特质数量、主原型、压力纹理和整合度
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│  人格细分密度            72 ↗+3      │
│  ┌───────────┐  ┌───────────┐       │
│  │清晰度 78%│  │稳定度 64%│       │
│  │████████░░│  │██████░░░░░│       │
│  └───────────┘  └───────────┘       │
│  ▣理性██ ▤敏感███ ▥控制██ ▦连接████│
│  ▧创造███ ▨秩序██ ▩自由█ □安全███ │
│  信号TOP3:连接·创造·敏感 ▸点选      │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：细分人格拼图

### 目标

底层人格由哪些细小部分共同构成。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 拼图块 | 细分特质 |
| 块大小 | 稳定程度 |
| 边缘连接 | 特质联动 |
| 主块 | 核心底纹 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│  ┌──────────┬─────┬────┐            │
│  │▣理性     │▤敏感│▥控制│   ◀主块   │
│  │ (大/稳)  │     │    │            │
│  ├──┬───────┘     └──╸─│  ◀联动边  │
│  │▦连接│ ▧创造     ▨秩序 │            │
│  ├──┴───────┬──────────┤            │
│  │ ▩自由    │  □安全   │            │
│  └──────────┴──────────┘            │
│  大块=稳定 连线=协同 ▸点击看表现    │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 你的底层人格由【特质A】、【特质B】和【特质C】共同构成。 |
| 展开解读 | 说明人格并非单一标签，重点解释矛盾特质如何共存。 |

### 展开解读示例

> 你的底层人格同时包含理性、敏感和控制感。外表稳定，但内里对关系反馈很敏锐；当安全感不足时，控制会迅速上升。

### 交互与动效

- 拼图块逐块拼合；点击块查看表现。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 12分行星位置、细分星座、特质映射。
