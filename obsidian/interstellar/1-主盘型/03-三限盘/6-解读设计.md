# 三限盘 · 解读设计

> 盘型定位：看清3—21天内的微周期体感、情绪转折与短时触发
> 核心问题：最近几天到几周，内在节奏怎样变化，哪里最敏感，何时需要换挡
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

脉冲、波形、闸门、热区、带宽；所有图形强调短周期与即时体感

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                              │
│ [专属视觉图表]                        │
│ 数据标签 / 状态 / 时间窗口            │
│ ────────────────────────────────── │
│ 一句话摘要（20—30字）                 │
│ 展开详细解读 ▸                        │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：微周期脉冲指数

- **视觉结构**：双弧脉冲仪：内弧为内在波动，外弧为外界触发；下方显示未来72小时趋势
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│微周期脉冲指数              68 活跃   │
│  ╭─外弧·外界触发──────────╮          │
│  │ ╭─内弧·内在波动───╮  │  72h趋势  │
│  │ │     68   内收   │  │  ─╱╲╱╲─→ │
│  │ ╰─────────────────╯  │  Now  48h │
│  ╰──────────────────────╯  ↑较昨日12 │
│  信号拆解: ①月触IC ②水入相 ③火精确  │
│  ▸点击信号查看底层来源              │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：当前微周期总览

### 目标

最近3—21天最核心的变化主线是什么。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 三段时间带 | 已发生 / 正增强 / 即将出现 |
| 主脉冲线 | 显示信号起伏与密度 |
| 体感标签 | 松、紧、躁、缓、收、放 |
| 强度点阵 | 1—5级 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│A 当前微周期总览                      │
│ ┌──过去────┬──正增强───┬──即将出现─┐│
│ │ ~~╱╲~~  │ ╱╲╱╲╱╲   │  ╱╲╱╲    ││
│ │  平缓    │  增强中   │ 峰值窗口  ││
│ │体感:●●●○ │节奏:加速  │方向:内收  ││
│ └──────────┴──────────┴──────────┘│
│ 强度点阵: ●●●●○  主线: 表达与边界   │
│ ▸点击时间段展开底层信号             │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 当前三限主线是【主题】，正从【旧状态】转向【新状态】。 |
| 展开解读 | 解释主线由哪些三限信号构成，说明当前是起势、峰值、缓冲还是收尾，并区分内在体感与外部触发。 |

### 展开解读示例

> 当前主线集中在表达与关系边界。过去几天的压抑感正在转为更直接的表达需求，未来48小时触发会更明显。此时适合先厘清自己真正要说什么，再决定是否立刻沟通。

### 交互与动效

- 脉冲线缓慢扫入；当前段轻微呼吸动画；点击时间段展开底层信号。
- 一阶段：点击"展开详细解读"显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 三限日/月/水星触发、精确度、入相出相、被触发本命点。
