# 13分盘 · 解读设计

> 盘型定位：看清非典型天赋、偏轨节律、突变式创造力和突破风险
> 核心问题：哪些特质不按常规运作，灵感在哪里落地，何时适合试错，怎样防止过冲
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

偏轴、条形码、断层、降落点、变异网络、临界平衡、折线路径；强调异常结构与突破

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                              │
│ [专属视觉图表]                        │
│ 数据标签 / 状态 / 时间窗口            │
│ ────────────────────────────────── │
│ 一句话摘要（20—30字）                 │
│ 展开详细解读 ▸                        │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：破格活跃指数

- **视觉结构**：偏轴主线 + 异常条形码；显示非典型特质密度、创造跃迁、风险临界和整合度
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│  破格活跃指数            68 ↗+5     │
│  ┌───────────┐  ┌───────────┐       │
│  │偏轴度 74%│  │变异密度58%│       │
│  │████████░░│  │██████░░░░░│       │
│  └───────────┘  └───────────┘       │
│  标准轴 ───────────────             │
│              ╲                       │
│               ╲● 你的破格主轴        │
│  信号:跳跃思维·独立性·反常识        │
│  ▸点选信号看详情                     │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：破格主轴图

### 目标

最核心的非典型主线是什么。

### 视觉元素

| 视觉元素 | 说明 |

| 标准轴 | 常规路径 |
| 偏轴 | 个人独特路径 |
| 偏离角度 | 差异程度 |
| 落点 | 现实应用方向 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│  标准轴 ────────────────────        │
│           ╲  偏离角度 23°            │
│            ╲                         │
│             ╲● 你的破格主轴          │
│              ╲──────→                │
│  ┌────────┐  ┌────────┐  ┌──────┐  │
│  │落点A   │  │落点B   │  │落点C │  │
│  │跨界    │  │项目制  │  │自定义│  │
│  └────────┘  └────────┘  └──────┘  │
│  ▸点击落点看方向 角度=差异度        │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 你的13分盘主线不是标准路径，而是围绕【主题】展开。 |
| 展开解读 | 解释偏离常规并不等于错误，重点是独特路径需要合适容器。 |

### 展开解读示例

> 你的主线明显偏离标准职业路径，更适合跨界、项目制和自定义角色。真正风险不是不稳定，而是没有承载独特性的结构。

### 交互与动效

- 偏轴从标准轴分离；落点脉冲。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 13分行星、相位、特质映射。
