# 天象盘 · 解读设计

> 盘型定位：理解外部集体环境
> 核心问题：当前集体环境中，哪些主题最值得关注
> 设计版本：V3.0
> 目标平台：iOS App

---

## 〇、平台设计原则（iOS App）

### 0.1 从 Web 到 App 的核心变化

| 维度 | Web 时代 | iOS App |
|---|---|---|
| 布局 | 右侧面板，空间受限 | 全屏卡片流，滚动自由 |
| 文字 | 极致压缩，能省则省 | 视觉 + 底部摘要 + 展开解读 |
| 交互 | 悬停为主，点击为辅 | 触控原生，点击/滑动/展开 |
| 阶段划分 | 一阶段纯展示/二阶段交互 | 展示层与交互层可更早融合 |

### 0.2 卡片文字层设计（核心规则）

每个卡片统一采用**视觉 + 摘要 + 展开**三层结构：

```text
┌──────────────────────────────────┐
│  卡片标题                         │
│                                  │
│  [视觉图表区]                     │
│  月相图标 / 三层周期条 / 比例条 / …  │
│                                  │
│  ──────────────────────────────  │
│  一句话摘要（始终可见，20—30字）    │
│  展开详细解读 ▸                   │
└──────────────────────────────────┘

点击展开后：

┌──────────────────────────────────┐
│  卡片标题                         │
│                                  │
│  [视觉图表区]                     │
│                                  │
│  ──────────────────────────────  │
│  一句话摘要                       │
│  ┌────────────────────────────┐  │
│  │ 详细解读（约100字）          │  │
│  │ 解释视觉图表的含义和当前状态  │  │
│  └────────────────────────────┘  │
│  收起 ▴                          │
└──────────────────────────────────┘
```

**文字层规范**：

| 层级 | 位置 | 字数 | 始终可见 | 说明 |
|---|---|---|---|---|
| 一句话摘要 | 卡片底部 | 20—30字 | 是 | 概括卡片核心结论，让用户一眼知道这张卡片在说什么 |
| 详细解读 | 展开区 | 约100字 | 否 | 解释视觉图表的含义，补充当前状态和注意事项 |

**设计原则**：
- 视觉为主，文字辅助——图表先说话，文字再解释
- 摘要必须能独立传达核心信息——用户不展开也能理解
- 详细解读不是重复图表，而是解释"这意味着什么"
- 原有文字内容保留，不过度增加

## 二、不推荐的右侧可视化

不建议使用：

- 今日吉凶分或单日行动评分
- 个人事件概率
- 每日情绪热力图
- 买入、卖出或投资建议
- "最好的一天""最差的一天"
- 将逆行直接标记为危险
- 将食相直接标记为灾难
- 大量占满右侧的专业参数表
- 仅用支持相位数量减去压力相位数量生成总分
- 将燃烧等同于行星失效

## 三、卡片A：当前天空总览

### 3.1 卡片目标

快速回答：当前天空主要在发生什么、长期背景是什么、中期推动是什么、近期触发是什么、当前月相处于什么阶段、集体氛围感受如何。

### 3.2 视觉元素

| 视觉元素 | 说明 | 数据来源 |
|---|---|---|
| 月相图标 | 圆形图示显示新月、上弦、满月、下弦及实际照明比例 | lunar_phase / illumination_fraction |
| 主线标题 | 8—18 字，显示当前最高权重主题 | theme_ranking[0] |
| 三层周期条 | 长期背景、中期趋势、短期触发三行 | cycle_level |
| 状态标签 | 支持、压力、转换、峰值、逆行等 | direction / time_phase |
| 逆行计数 | 显示当前逆行行星数量 | planets.retrograde |
| 天空主导对象 | 显示当前权重最高的 2—3 个行星或相位 | dominant_signals |
| 集体氛围标签 | 紧迫/沉稳/混乱/活跃/过渡/密集，整体感受维度 | atmosphere_tag |

### 3.3 视觉示意

```text
┌──────────────────────────────────────────┐
│  ◕  当前天空总览                          │
│  信息加速，规则与事实核验同步增强           │
│                                          │
│  长期背景  土星六合天王星   [结构更新]      │
│  中期趋势  水星刑土星       [压力增强]      │
│  短期触发  满月接近精确     [24小时内]      │
│                                          │
│  月相：盈凸月 82%                         │
│  逆行：3颗   主导：水星 / 土星 / 天王星    │
│  氛围：活跃                               │
│                                          │
│  信息加速与规则收紧同时出现，集体氛围活跃    │
│  展开详细解读 ▸                           │
└──────────────────────────────────────────┘
```

### 3.4 文字层

| 层级 | 内容 | 语料来源 |
|---|---|---|
| 一句话摘要 | 【主题】与【主题】同时出现，集体氛围【氛围】 | 慢行星语料 + 氛围语料 |
| 展开解读（~100字） | 说明三层周期条的含义：长期背景由慢行星结构推动，中期由中速行星强化，短期触发使主题在近日更加明显。月相阶段影响集体情绪节奏。 | 时间尺度语料 + 氛围语料 + 月相语料 |

展开解读示例：

> 当前天空主线是信息加速与规则收紧同时出现。长期背景由土星六合天王星推动结构更新，中期水星刑土星带来信息与规则的摩擦，短期满月接近精确使已有议题进入显化阶段。盈凸月阶段集体情绪仍在累积，尚未到达峰值。氛围标签"活跃"表示多颗行星入相，新事件密集——变化节奏加快，但方向尚未完全明确。

### 3.5 三层周期条设计

每行包含：周期层级 / 主导事件 / 方向标签 / 持续时间

颜色建议：

- 长期背景：深紫或深蓝
- 中期趋势：蓝色
- 短期触发：浅灰或橙色
- 支持：绿色 / 压力：红色 / 转换：黄色 / 中性：灰色

颜色只用于区分，不单独承担结论。

### 3.6 集体氛围标签

| 氛围 | 含义 | 触发条件 | 视觉建议 |
|---|---|---|---|
| 紧迫 | 多颗快行星入相精确，压力相位集中 | pressure_weight > 60% 且短期事件密集 | 橙红色调 |
| 沉稳 | 慢行星拱相主导，快行星出相 | support_weight > 50% 且无高权重短期事件 | 蓝灰色调 |
| 混乱 | 逆行潮（≥3颗逆行），多信号冲突方向 | retrograde_count ≥ 3 且 direction 分布分散 | 紫色调 |
| 活跃 | 多颗行星入相，新事件密集 | 入相相位数 ≥ 出相相位数 × 2 | 绿色调 |
| 过渡 | 旧事件出相，新事件尚未入相 | 出相为主且无强入相信号 | 灰黄色调 |
| 密集 | 大型结构形成 | pattern_count > 0 | 深蓝色调 |

氛围标签放在主线标题下方、三层周期条上方，以紧凑色块形式呈现。

### 3.7 生成规则

长期背景优先：慢行星换座 > 慢行星精确相位 > 土星及外行星顺逆行转换

中期趋势优先：太阳/水星/金星/火星换座 > 中速行星精确相位 > 水星/金星/火星顺逆行

短期触发优先：新月/满月/食相 > 月亮触发长期结构 > 24—72小时内精确相位

若短期没有高权重触发，显示：

> 短期结构相对平稳，长期主题继续延续。

### 4.4 文字层

| 层级 | 内容 | 语料来源 |
|---|---|---|
| 一句话摘要 | 【前三个主题】是当前最活跃的集体主题 | 主题整合语料 |

展开解读示例：

> 信息传播主题强度最高（4级），水星刑土星使消息速度加快但规则核验同步增强。规则与结构主题正在调整（3级），土星六合天王星推动旧流程接受新条件检验，持续数月。关系合作主题支持与压力并存，金星拱木星提供协商空间，但金星刑冥王星要求处理价值与权力的深层分歧。强度条反映信号集中度，不表示事件概率。

### 4.6 排序与数量

- 默认展示前 3 个主题

- 完整信号列表进入展开层

## 五、卡片C：关键天象事件

按时间顺序展示未来时间窗口内最重要的天象节点，包含阴影期、燃烧/日心状态和多次精确相位。

默认时间范围：未来 30 天（一阶段固定 30 天，不提供切换）。

> 二阶段：增加 7 天 / 30 天 / 90 天切换控件。

### 5.2 视觉元素

| 视觉元素 | 说明 | 数据来源 |
|---|---|---|
| 纵向时间轴 | 按日期从近到远排列 | event_date |
| 事件图标 | 相位、换座、逆行、顺行、月相、食相、阴影期、燃烧 | event_type |
| 强度圆点 | 红=高压，绿=支持，黄=转换，灰=背景 | direction/intensity |
| 时间标签 | 今天、24 小时内、7 天内、具体日期 | event_date |
| 当前状态 | 入相、精确、出相、换座前、留、前阴影、后阴影、燃烧、日心 | time_phase |
| 主题说明 | 一句话解释事件含义 | event_corpus |
| 精确次数 | 多次精确时显示"第N次/共N次" | exact_count / exact_index |

### 5.4 文字层

| 层级 | 内容 | 语料来源 |
|---|---|---|
| 一句话摘要 | 【最强事件】【状态】，后续【预告】 | 事件语料 + 运行状态语料 |
| 展开解读（~100字） | 说明时间线上最重要的1—2个事件、方向和时间窗口，提醒多次精确相位是完整周期不能只看一次，行星状态事件（阴影期/燃烧）的含义。 | 相位语料 + 运行状态语料 + 行星状态语料 |

展开解读示例：

> 水星刑土星今日精确（第1次/共3次），信息与规则之间的摩擦达到峰值。因逆行这一相位将精确3次，当前只是首次集中，后续还会反复。8月5日水星进入逆行前阴影期，信息议题开始显现，后续会反复出现。满月使已有议题显化，金星进入燃烧区后关系信号可见度暂时下降。强度圆点颜色表示方向，非吉凶——红=压力/需调整，绿=支持/可利用。

### 5.5 事件优先级

```text
日月食
> 慢行星换座
> 慢行星精确相位
> 顺逆行转换与留
> 逆行前阴影期进入
> 大型相位结构形成或解除
> 快速行星换座和精确相位
> 新月、满月
> 行星进入/离开燃烧区
> 逆行后阴影期结束
> 月亮短期相位
```

月亮普通相位只在 7 天视图展示。

### 5.6 多次精确相位展示规则

- 后阴影结束：标记为"逐步脱离"，提示议题回到正常轨道
