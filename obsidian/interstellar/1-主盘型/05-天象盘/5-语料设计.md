# 天象盘 · 语料设计

> 盘型定位：理解外部集体环境
> 核心问题：当前集体环境中，哪些主题最值得关注
> 语料版本：V3.0
> 目标平台：iOS App

---

## 一、天象盘专用组合句模板

> 【行星A】与【行星B】形成【相位】，集体环境中与【社会主题】有关的议题可能更加活跃。相关影响更容易表现为【外部领域】，整体氛围呈现【状态词】。

### 行星→社会主题映射表

| 行星 | 集体环境主题 |
|---|---|
| 太阳 | 权威、领导力、公开形象、国家元首 |
| 月亮 | 民生、公众情绪、家庭政策、女性议题 |
| 水星 | 信息传播、交通、教育、媒体、通讯技术 |
| 金星 | 消费、金融、审美趋势、关系模式、文化消费 |
| 火星 | 冲突、军事、竞争、体育、行动节奏 |
| 木星 | 法律、教育、国际关系、宗教、扩张、经济政策 |
| 土星 | 制度、规则、责任、紧缩、建筑、长者 |
| 天王星 | 科技突破、社会改革、突发变化、互联网 |
| 海王星 | 文化艺术、舆论迷惑、医疗、宗教灵性、模糊边界 |
| 冥王星 | 权力结构、危机、资源再分配、深层改革 |

## 二、语料体系目标与边界

### 2.1 语料回答的六个问题

1. 当前天空最核心的主题是什么
2. 哪些行星和相位构成主要推动力
3. 当前处于平稳期、增强期、峰值期还是转换期
4. 接下来有哪些关键天象事件
5. 哪些社会与生活领域更容易受到象征性影响
6. 用户怎样将天象盘与个人本命盘连接

推荐生成链路：

```text
行星位置
→ 星座表达
→ 行星状态（含阴影期、燃烧等）
→ 主要相位（含多次精确）
→ 天象事件
→ 结构模式
→ 主题聚合
→ 时间窗口
→ 右侧重点语料
```

### 2.2 适合表达的内容

- 当前天空主题与集体氛围
- 信息、关系、行动、规则、创新等领域的象征性变化
- 行星换座、逆行、顺行、留、精确相位、月相和食相
- 逆行阴影期、多次精确相位、逆行潮
- 行星燃烧与日心状态
- 月交点换座与合相
- 长周期背景与短周期触发
- 支持、压力、转换和整合
- 未来重要天象窗口

### 2.3 不直接表达的内容

- 个人必然发生的事件
- 单日吉凶或投资买卖结论
- 精确事件概率
- 医疗、法律或财务决策
- 将天象强度分数解释为现实事件准确率

### 2.4 推荐主语

优先使用：

```text
当前天空 / 当前天象 / 集体氛围 / 公共议题 / 相关领域 / 这一阶段 / 未来一段时间
```

个人层面统一使用提示：

> 个人感受取决于天象与本命行星、四轴和宫位的具体连接。

## 三、语料字段设计

每条语料建议包含：

| 字段 | 说明 | 示例 |
|---|---|---|
| corpus_id | 唯一编号 | `SKY_RIGHT_THEME_COMMUNICATION_01` |
| chart_type | 盘型 | `mundane_sky_chart` |
| display_zone | 展示区域 | `right_panel` |
| corpus_layer | 语料层级 | `theme_summary` |
| object_type | 对象类型 | `planet_aspect` |
| object_key | 对象键 | `mercury_square_saturn` |
| event_type | 事件类型 | `exact_aspect` |
| theme_keys | 主题标签 | `communication,rules,information` |
| direction | 支持、压力、中性、混合 | `pressure` |
| cycle_level | 短期、中期、长期 | `short_term` |
| time_phase | 入相、精确、出相、转换等 | `applying` |
| intensity | 1—5 级 | `4` |
| duration | 预计持续时间 | `12_days` |
| usage_position | 标题、摘要、事件、提示等 | `right_theme_summary` |
| length_level | 极短、短、标准 | `short` |
| text | 语料正文 | `信息传播与规则要求之间的摩擦正在增强。` |
| variables | 可替换变量 | `planet_a,planet_b,date` |
| card_summary | string | 否 | 卡片底部一句话摘要，20—30字，始终可见 |
| card_detail | string | 否 | 展开详细解读，约100字，解释视觉图表含义 |
| mutex_group | 互斥组 | `communication_pressure_title` |
| priority | 展示优先级 | `90` |
| enabled | 是否启用 | `true` |

语料 ID 命名规范：

```text
SKY_RIGHT_对象或主题_用途_序号
```

示例：

```text
SKY_RIGHT_MERCURY_SQ_SATURN_SUMMARY_01
SKY_RIGHT_THEME_COMMUNICATION_TITLE_01
SKY_RIGHT_EVENT_RETROGRADE_MERCURY_01
SKY_RIGHT_DOMAIN_INFORMATION_PRESSURE_01
```

## 四、语料分层

| 层级 | 作用 | 示例 |
|---|---|---|
| 基础词语 | 强度、方向、阶段和领域标签 | 增强、收缩、转折、信息传播 |
| 单行星语料 | 解释行星当前功能 | 水星强调信息与沟通 |
| 行星状态语料 | 解释行星当前运行状态（含燃烧、阴影等） | 水星靠近太阳，信息信号被遮蔽 |
| 行星落座语料 | 解释行星如何表达 | 水星在白羊座使表达更直接 |
| 相位与结构语料 | 解释行星之间如何互动（含多次精确） | 火星刑土星形成行动与限制的摩擦 |
| 事件语料 | 解释换座、逆行、顺行、月相等 | 水星开始逆行，信息进入复核期 |
| 月交点语料 | 解释南北交点的集体方向 | 南交点在天蝎座，集体正在释放控制模式 |
| 主题整合语料 | 合并多项天象形成右侧结论 | 信息加速与规则收紧同时出现 |
| 氛围语料 | 描述集体环境的整体感受 | 紧迫、沉稳、混乱、活跃 |

## 五、时间尺度语料

### 5.1 长期背景（慢行星与月交点）

主要对象：木星、土星、天王星、海王星、冥王星、南北交点

- 当前长期背景强调【主题】。这一趋势会持续数月或更长时间。
- 慢行星之间的结构正在推动【领域】发生持续调整。
- 当前变化更接近阶段背景，短期事件只是其表现形式。
- 长周期信号仍在发展，不宜根据单一日期判断结果。
- 长期背景提供方向，具体触发需要结合快速行星和月相。
- 月交点位于【星座轴线】，集体成长方向指向【北交点星座主题】。

### 5.2 中期趋势（中速行星）

主要对象：太阳、水星、金星、火星、月相周期

- 未来数周的主要主题集中在【主题】。
- 太阳、金星、火星或水星正在把长期背景带入日常层面。
- 中期趋势会影响公共讨论、合作节奏和行动方式。
- 当前主题会在下一次换座或顺逆行转换后发生变化。

### 5.3 短期触发（月亮与精确事件）

主要对象：月亮、精确相位、换座、留、食相

- 当前接近一个明显的短期触发点。
- 精确相位附近，相关主题最容易集中出现。
- 月亮正在激活已有的长期结构。
- 短期波动较强，长期背景保持不变。
- 短期触发结束后，整体趋势仍需参考慢行星结构。

## 六、强度与阶段词库

### 6.1 强度词

| 等级 | 右侧标签 | 正文表达 |
|---|---|---|
| 5 | 核心主导 | 当前天空的主要力量集中在这一主题 |
| 4 | 明显增强 | 相关氛围和议题更容易被察觉 |
| 3 | 持续活跃 | 这一主题保持一定影响 |
| 2 | 局部触发 | 主要在特定情境中表现 |
| 1 | 背景信号 | 暂不构成当前主线 |

### 6.2 阶段状态

| 状态 | 右侧标签 | 语料 |
|---|---|---|
| 入相 | 持续增强 | 相关力量正在靠近，主题会逐渐增强 |
| 接近精确 | 接近峰值 | 当前已进入影响较集中的阶段 |
| 精确 | 当前峰值 | 相关主题在这一时间附近最为集中 |
| 出相 | 开始减弱 | 最强阶段已经过去，影响正在缓慢减弱 |
| 第一次精确 | 首次集中 | 同一相位的第一次精确，主题首次集中显现 |
| 逆行中精确 | 回顾中确认 | 逆行期再次精确，相关议题重新浮现等待确认 |
| 最后一次精确 | 最终确认 | 第三次精确后主题进入落实阶段 |
| 换座前 | 即将转换 | 行星表达方式即将发生变化 |
| 换座后 | 新阶段建立 | 新的表达方式开始进入集体环境 |
| 前阴影进入 | 开始显现 | 逆行阴影期开始，相关议题进入觉察范围 |
| 前阴影结束 | 即将逆行 | 阴影期接近逆行点，问题更加明显 |
| 后阴影进入 | 仍在消化 | 逆行结束但仍处于阴影区，相关议题需要时间完全消化 |
| 后阴影结束 | 逐步脱离 | 阴影期完全结束，相关议题回到正常轨道 |
| 留 | 高度集中 | 行星速度接近停滞，相关主题被持续放大 |
| 逆行 | 回顾调整 | 相关领域进入复核、反思和重新处理阶段 |
| 顺行恢复 | 重新推进 | 前期反复的问题开始恢复向前发展 |
| 燃烧 | 信号遮蔽 | 行星靠近太阳，相关主题可见度下降 |
| 日心 | 深度重塑 | 行星极其接近太阳，主题被重新定义 |
| 燃烧恢复 | 重新显现 | 行星脱离太阳遮蔽，议题重新获得可见度 |

### 6.3 方向词

- **支持**：协调、连接、扩展、稳定、修复、推动、开放、整合、澄清、落实、恢复、建立
- **压力**：摩擦、限制、分化、延迟、失衡、过载、收缩、放大、反复、模糊、对立、冲突
- **转换**：切换、转向、更新、重组、交替、迁移、松动、进入新阶段、重新定位

## 七、十大行星天象语料

### 7.1 太阳

**核心主题：** 关注中心、领导、公开表达、目标、权威、可见度

- 当前公共注意力集中在【领域】
- 领导、目标和公开表达成为主要议题
- 某一主题正在获得更高可见度
- 权威立场和集体方向更容易被讨论
- 太阳换座后，集体关注中心开始转移
- 公开立场容易强化分化
- 对认可和权威的敏感度上升

### 7.2 月亮

**核心主题：** 集体情绪、公众反应、民生、安全感、短期氛围

- 集体情绪对外部信息更加敏感
- 公众关注点正在快速变化
- 安全感、家庭和民生议题更容易引发回应
- 月亮正在短期激活【长期主题】
- 当前情绪波动较强，持续时间相对有限
- 即时情绪可能放大判断偏差
- 群体氛围容易出现快速转向

### 7.3 水星

**核心主题：** 信息、传播、沟通、交通、学习、交易、技术接口

- 信息传播和公共讨论明显活跃
- 沟通、文件和规则确认成为重点
- 新消息正在改变原有判断
- 信息连接速度提高
- 水星换座使表达和判断方式发生变化
- 信息过载和误解风险上升
- 消息速度可能快于事实确认

### 7.4 金星

**核心主题：** 关系、合作、价值、消费、审美、外交、资源交换

- 合作、关系和价值判断成为主要议题
- 公共审美和消费偏好正在变化
- 协商和关系修复空间增加
- 资源交换和合作条件受到关注
- 金星换座后，集体价值偏好开始转向
- 表面和谐可能掩盖真实分歧
- 对价格、价值和公平的敏感度上升

### 7.5 火星

**核心主题：** 行动、竞争、冲突、执行、边界、风险、推进速度

- 行动力和竞争氛围明显增强
- 相关领域进入加速推进期
- 边界、立场和资源争取更加直接
- 集体行动意愿上升
- 火星正在把长期议题推入现实处理
- 急迫感和对抗性上升
- 行动速度可能超过风险评估

### 7.6 木星

**核心主题：** 扩展、增长、教育、法律、国际、信念、市场预期

- 扩展和发展预期正在增强
- 教育、法律和跨区域议题受到关注
- 新机会和新叙事开始扩大影响
- 集体信心和发展愿望有所提高
- 木星换座会改变未来一年的扩展重点
- 乐观预期可能高于现实条件
- 扩张速度可能超过资源承受能力

### 7.7 土星

**核心主题：** 规则、责任、限制、制度、成本、结构、长期建设

- 规则、责任和现实条件成为主要限制
- 集体环境更强调秩序和长期结构
- 某些领域进入收缩、审查或重建期
- 时间和成本要求更加明确
- 土星正在推动旧结构接受现实检验
- 进展速度可能放缓
- 高压结构需要重新分配负担

### 7.8 天王星

**核心主题：** 突变、创新、科技、自由、改革、断裂、意外

- 创新和突破需求明显增强
- 技术、制度和生活方式可能快速更新
- 旧规则受到新方法挑战
- 突发变化更容易改变原有节奏
- 天王星换座会开启较长的时代主题转换
- 变化速度可能超过适应能力
- 新方案仍需验证稳定性

### 7.9 海王星

**核心主题：** 理想、想象、文化、信任、模糊、融合、传播感染

- 集体想象和文化情绪明显增强
- 理想、信任和精神议题获得关注
- 边界趋于模糊，跨领域融合增加
- 艺术、影像和情绪传播的影响上升
- 海王星换座会改变较长时期的集体想象
- 信息真实性和责任边界需要核实
- 理想化和失望可能交替出现

### 7.10 冥王星

**核心主题：** 权力、深层转化、控制、资源重组、危机、不可逆变化

- 权力和资源结构正在发生深层调整
- 隐藏较久的问题更容易被暴露
- 某些旧结构进入不可逆的重组过程
- 控制、垄断和资源分配成为核心议题
- 冥王星换座开启长期时代结构转换
- 权力对抗和极端化倾向上升
- 深层变化持续时间较长，短期难以完成

## 九、主要相位天象语料

### 9.1 合相

- 两股力量正在集中
