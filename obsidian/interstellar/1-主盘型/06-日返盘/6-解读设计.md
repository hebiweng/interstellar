# 日返盘 · 解读设计

> 盘型定位：看清生日到下一次生日之间的年度主轴、季度节奏与关键月份
> 核心问题：这一岁最重要的方向是什么，什么时候发力，什么时候调整，全年资源应放在哪里
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

罗盘、年环、地形、天际线、桥梁、路线书；强调全年规划与阶段推进

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                              │
│ [专属视觉图表]                        │
│ 数据标签 / 状态 / 时间窗口            │
│ ────────────────────────────────── │
│ 一句话摘要（20—30字）                 │
│ 展开详细解读 ▸                        │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：年度主轴指数

- **视觉结构**：年度罗盘 + 四季度坡度；中心显示主轴清晰度，外圈显示事业、关系、资源、内在四向权重
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ ◢◣ 年度主轴指数      72/100 ▲+8 活跃  │
│ ┌──────── 年度罗盘 ────────┐         │
│ │      N ↑ 事业 28          │         │
│ │ W18 ← ◎ 主轴 → E26 资源    │         │
│ │      S ↓ 内在 16          │         │
│ └──────────────────────────┘         │
│ 子指标: 主题密度38 │ 结构清晰34       │
│ 信号 ①日返上升×MC ②太阳10宫 ③木土    │
│ ◦ 点击罗盘方向 → 展开领域详情 ▸        │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：年度主轴罗盘

### 目标

这一岁最重要的方向是什么。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 中心主轴 | 年度核心主题 |
| 四向权重 | 事业/关系/资源/内在 |
| 指针方向 | 当前最强方向 |
| 清晰度 | 主轴集中程度 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ A 年度主轴罗盘           清晰度 72%   │
│         N · 事业 28                   │
│ W 18 ← ◉ 年度核心主题 → 资源 E 26     │
│         S · 内在 16                   │
│ 指针角度: 12° 偏向事业 ▸               │
│ 主轴主题: 公开角色与稳定身份            │
│ ──────────────────────────────────  │
│ 力量指向【事业/定位】▸ 展开解读        │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 这一年最重要的主轴是【主题】，力量主要指向【方向】。 |
| 展开解读 | 解释年度主轴由日返上升、太阳、月亮、四轴和主星共同形成，并指出它是全年背景而非单一事件。 |

### 展开解读示例

> 本年度主轴落在事业定位与公开角色。你会更在意自己被如何看见，也更需要建立可持续的位置。关系与资源是辅助线，真正的核心是把能力转化成稳定身份。

### 交互与动效

- 罗盘指针从0旋转到目标角度；点击方向展开领域。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 日返上升、太阳、主星、四轴、年度主题评分。

## 4、卡片B：12个月节律环

### 视觉元素

```text
│ ╭──────────────────────────────╮    │
│ │    ◉ 年度节律环              │    │
│ │  ▲峰值 ◆转折 ●缓冲 ★当前月   │    │
│ ╰──────────────────────────────╯    │
│   07▆ 08█ 09▇ 10▅ 11▄ 12▃          │
│ 当前【08】█ | 转折【09】◆           │
│ ◦ 点击月份 → 浮层显示触发信号 ▸      │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 【月份】到【月份】是本年度最关键的节奏带。 |
| 展开解读 | 说明高强度月、转折月和恢复月的差异，避免把深色月份直接解释成坏月。 |

### 展开解读示例

### 交互与动效

- 年环缓慢展开；拖动月份显示浮层。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 月份触发、行运叠加、月返评分、事件窗口。

## 5、卡片C：四季度地形图

### 目标

每个季度的任务密度和节奏如何。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 四段地形 | Q1—Q4 |
| 高度 | 任务密度 |
| 坡度 | 节奏变化 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ C 四季度地形图          峰值: Q3     │
│ 高┤          ▆█                      │
│   │      ▅▆   ▅▄                     │
│   │  ▃▄                             │
│ 低┤  ▂▃                             │
│   └──Q1──Q2──Q3──Q4──                │
│   建基  推进  峰值  收束              │
│ 高度=任务密度  坡度=节奏变化           │
│ ◦ 点击季度 → 展开任务清单 ▸           │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 最适合集中发力的是【季度】，最适合整理的是【季度】。 |
| 展开解读 | 把年度节奏组织成四个阶段，说明不同季度该用不同策略。 |

### 展开解读示例

> 第一季度更适合建基，第二季度开始加速，第三季度进入全年峰值，第四季度收束。若全年一直用同样强度推进，反而容易在峰值前透支。

### 交互与动效

- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 季度聚合分数、月份强度、阶段语料。

## 9、卡片G：资源蓄水池

### 目标

金钱、时间、人脉和支持系统是累积还是消耗。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 输入管道 | 收入/支持/人脉 |
| 水位 | 资源储备 |
| 输出管道 | 支出/消耗 |
| 净变化 | 累积/流动/消耗 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ G 资源蓄水池          净变化: 累积↑  │
│ 收入 ─┐                             │
│ 人脉 ─┤ ╔════════════════╗         │
│ 支持 ─┘ ║   资源水位      ║ → 支出  │
│         ║   ████░░ 64%   ║   消耗  │
│         ╚════════════════╝         │
│ 输入3管道│储备64%│输出2管道          │
│ Q3输出↑ 建议保留机动空间             │
│ ◦ 点击管道 → 查看构成明细 ▸         │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 本年度资源状态偏【累积/流动/消耗】，关键在【原因】。 |
| 展开解读 | 同时解释财务与广义资源，指出什么时候适合扩张，什么时候需保留缓冲。 |
