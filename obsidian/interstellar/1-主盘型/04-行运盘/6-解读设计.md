# 行运盘 · 解读设计

> 盘型定位：看清当前变化和时间窗口
> 核心问题：现在最重要的变化是什么，什么时候最明显，怎么处理
> 设计版本：V4.0
> 目标平台：iOS App

---

## 〇、平台设计原则（iOS App）

### 0.1 从 Web 到 App 的核心变化

| 维度 | Web 时代 | iOS App |
|---|---|---|
| 布局 | 右侧面板，空间受限 | 全屏卡片流，滚动自由 |
| 文字 | 极致压缩，能省则省 | 视觉 + 底部摘要 + 展开解读 |
| 交互 | 悬停为主，点击为辅 | 触控原生，点击/滑动/展开 |
| 阶段划分 | 一阶段纯展示/二阶段交互 | 展示层与交互层可更早融合 |

### 0.2 卡片文字层设计（核心规则）

每个卡片统一采用**视觉 + 摘要 + 展开**三层结构：

```text
┌──────────────────────────────────┐
│  卡片标题                         │
│                                  │
│  [视觉图表区]                     │
│  仪表盘 / 雷达图 / 甘特条 / …     │
│                                  │
│  ──────────────────────────────  │
│  一句话摘要（始终可见，20—30字）    │
│  展开详细解读 ▸                   │
└──────────────────────────────────┘

点击展开后：

┌──────────────────────────────────┐
│  卡片标题                         │
│                                  │
│  [视觉图表区]                     │
│                                  │
│  ──────────────────────────────  │
│  一句话摘要                       │
│  ┌────────────────────────────┐  │
│  │ 详细解读（约100字）          │  │
│  │ 解释视觉图表的含义、当前状态  │  │
│  │ 和需要注意的事项             │  │
│  └────────────────────────────┘  │
│  收起 ▴                          │
└──────────────────────────────────┘
```

**文字层规范**：

| 层级 | 位置 | 字数 | 始终可见 | 说明 |
|---|---|---|---|---|
| 一句话摘要 | 卡片底部 | 20—30字 | 是 | 概括卡片核心结论，让用户一眼知道这张卡片在说什么 |
| 详细解读 | 展开区 | 约100字 | 否 | 解释视觉图表的含义，补充当前状态和注意事项 |

**设计原则**：
- 视觉为主，文字辅助——图表先说话，文字再解释
- 摘要必须能独立传达核心信息——用户不展开也能理解
- 详细解读不是重复图表，而是解释"这意味着什么"
- 原有文字内容保留，不过度增加

## 二、不推荐的右侧可视化

不建议使用：

- 天象描述代替个人影响（应说"行运土星正在触发你的本命冥王星"）
- 过度笼统（"这段时间要注意"）
- 单一时间点无窗口（"3月15日会发生XX"）
- 只写精确当天忽略入相/出相
- 把压力行运写成灾难
- 把支持行运写成保证成功
- 无条件的确定性预测（"下个月你会升职"）
- 伪概率值（"80%可能遇到贵人"）

## 三、日活跃度指数（顶部固定区）

### 3.1 位置与目标

固定在解读页最顶部，全天候可见。用户一打开行运盘就能看到今天的行运有多活跃。

### 3.2 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 半圆弧仪表盘 | 0—100 分刻度，指针指向当日指数 |
| 数字 | 今日活跃度：68/100 |
| 等级标签 | 静默/轻度/活跃/高活跃/密集 |
| 推动指数 | 绿色子指标 |
| 调整指数 | 红色子指标 |
| 趋势箭头 | 与昨日对比（↑上升 / →平稳 / ↓下降） |

### 3.3 视觉示意

```text
┌──────────────────────────────────────────┐
│              ╭─────────╮                  │
│           ╱    68      ╲                 │
│         ╱   ────●────   ╲               │
│        │  静默  轻度 活跃 高 密集│              │
│              ╰─────────╯                  │
│     推动指数 28  调整指数 40  ↑较昨日+12    │
│                                          │
│  今日行运信号密集，调整需求高于推进机会      │
│  展开详细解读 ▸                           │
└──────────────────────────────────────────┘
```

### 3.4 文字层

| 层级 | 内容 | 语料来源 |
|---|---|---|
| 一句话摘要 | 今日行运信号【等级】，【方向】需求【比较】推进机会 | 日活跃度指数语料 |
| 展开解读（~100字） | 说明当前指数的含义：高分不等于好运气，低分也不代表无事可做。指出推动和调整分别来自哪些行运信号，以及与昨日的趋势变化。 | 日活跃度指数语料 + 指数拆解语料 |

展开解读示例：

> 今日活跃度68分，处于高活跃区间。调整需求（40分）高于推进条件（28分），行运火星刑本命月亮是主要压力来源，木星拱金星提供部分调整空间。较昨日上升12分，因火星接近精确相位。高活跃意味着行运信号密集，个人体验可能出现较明显变化，但不直接等同于好坏。

### 3.5 点击拆解

> 二阶段：点击仪表盘展开底层信号拆解，显示每个行运信号对当日指数的贡献。一阶段点击展开详细解读，信号拆解在解读区内以列表形式呈现。

### 3.6 颜色规则

| 等级 | 分数 | 仪表盘颜色 |
|---|---|---|
| 静默 | 0—20 | 深蓝灰色 |
| 轻度 | 21—40 | 浅蓝色 |
| 活跃 | 41—60 | 蓝绿色 |
| 高活跃 | 61—80 | 橙色 |
| 密集 | 81—100 | 红橙色 |

### 4.4 文字层

| 层级 | 内容 | 语料来源 |
|---|---|---|

### 4.5 行运节奏波形

| 节奏 | 波形线 | 含义 |
|---|---|---|
| 加速 | 〿 上升波 | 多颗入相，节奏加快 |
| 稳定 | 〰 平稳波 | 出相为主，延续状态 |
| 反复 | ≋ 震荡波 | 逆行多，进展反复 |
| 集中 | ∧ 尖峰波 | 信号密集精确 |
| 过渡 | ∿ 过渡波 | 旧出相新入相 |

## 六、卡片C：关键行运事件

### 6.1 卡片目标

用时间线+甘特条展示未来30天最重要的行运事件。

默认时间范围：未来 30 天（一阶段固定 30 天）。

### 6.2 视觉元素


### 6.4 文字层

| 层级 | 内容 | 语料来源 |
|---|---|---|
| 一句话摘要 | 近期【最强事件】是主要【方向】节点 | 相位语料 + 事件语料 |
| 展开解读（~100字） | 说明时间线上最重要的1—2个事件、它们的时间窗口和方向，提醒注意入相期感受已开始、精确日前后最集中、出相期影响仍需消化。 | 相位语料 + 时间窗口语料 |

展开解读示例：

> 时间线上最重要的事件是火星刑月亮（8月4日精确），压力方向，家庭与情绪领域影响最明显。目前处于入相阶段，相关感受已在增强。金星过第7宫（8月初）带来关系领域的活跃，水星进入逆行前阴影期后信息议题会反复出现。甘特条越长表示影响窗口越宽，实心圆点表示精确时间。

### 6.5 甘特条规则

- 入相阶段：较淡颜色条
- 精确点：实心圆点或加粗
- 出相阶段：虚线或更淡条
- 多次精确：甘特条分段
- 长期行运：右侧截断标注"→持续"

### 6.6 事件展开层

> 二阶段：点击甘特条展开详情。一阶段展开解读区内简要列出事件含义。

## 七、卡片D：支持与压力

### 7.1 视觉元素

| 视觉元素 | 说明 |

## 二十一、边界说明

- 日活跃度指数反映行运信号集中度，不是运气好坏
- 敏感度指标反映领域被激活程度，不是事件发生概率
- 趋势条件句必须带条件前提，不写无条件必然结果
- 所有评分可追溯到 source_transit_ids 和 corpus_id
- 月亮短期行运不覆盖慢行星主线
