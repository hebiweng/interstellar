# 行运盘 · 语料设计

> 盘型定位：看清当前变化和时间窗口
> 核心问题：现在最重要的变化是什么，什么时候最明显，怎么处理
> 语料版本：V4.0
> 目标平台：iOS App

---

## 一、行运盘专用组合句模板

### 1.1 行运触发本命（核心句式）

**通用句**：行运【行星A】正在触发本命【行星B】，近期【个人主题】会更加活跃。

**入相句**：这一影响正在增强，相关感受或事件出现频率可能逐步上升。

**精确句**：当前接近精确相位，【个人主题】更容易集中表现。

**出相句**：最强阶段已经过去，后续重点逐渐转向处理结果和完成收尾。

**现实句**：如果现实中已经存在【问题】，这一阶段更容易推动它进入明确处理。

### 1.2 行运行星过宫

> 行运【行星】进入本命第【宫位】宫，未来一段时间内，【宫位领域】会更加活跃。相关状态可能表现为【行星用户状态语料】，建议优先处理【行星建议语料】。

### 1.3 逆行周期组合

**逆行前阴影**：相关主题即将进入回顾和调整阶段，当前仍可推进，但建议保留调整空间。

**逆行中**：相关主题进入回顾和调整阶段，旧问题可能再次出现，进展可能发生反复，更适合复盘、修正和补充。

**留点**：相关主题处于高度集中状态，表面进展有限但内部压力正在积累。

**恢复顺行**：反复状态开始逐渐结束，原有问题有机会进入解决阶段。

**后阴影**：前期修正结果开始进入实施阶段，但需确认方向已稳定。

### 1.4 行运触发本命四轴

> 行运【行星】正在触发本命【四轴名称】，【四轴领域】近期会出现更明显的变化信号。行运行星触犯四轴的影响比触犯普通行星更显著，因为四轴是个人生活中最敏感的结构点。

| 四轴 | 触发领域 |
|---|---|
| 上升点 | 个人形象、自我认知、身体状态、新开始的触发 |
| 下降点 | 一对一关系、合作、伴侣、公开对手 |
| 天顶 | 事业方向、公共角色、社会地位、长期目标 |
| 天底 | 家庭、居住、内在安全感、根基 |

### 1.5 多次精确相位组合

同一行运行星因逆行多次触发同一本命点时：

**第一次精确**：相关主题首次集中表现，开始进入明确处理阶段。

**逆行中精确**：主题回到焦点，之前处理的结果接受回顾和修正。

**最后一次精确**：主题最终确认，修正结果进入落实阶段。

## 二、语料体系目标与边界

### 2.1 语料回答的六个问题

1. 当前最重要的个人变化是什么
2. 哪些行运行星正在触发本命敏感点
3. 当前处于增强期、峰值期还是收尾期
4. 接下来有哪些关键行运事件
5. 哪些个人生活领域更容易受到直接影响
6. 当前适合推进、调整还是等待

推荐生成链路：

```text
行运行星位置
→ 行运与本命的相位关系
→ 行运行星状态（含逆行周期、阴影期、燃烧等）
→ 被触发的本命行星/四轴/宫位
→ 触发的时间阶段（入相/精确/出相）
→ 支持/压力判断
→ 个人主题聚合
→ 时间窗口
→ 行动建议
→ 右侧重点语料
```

### 2.2 适合表达的内容

- 当前最重要的行运触发及其个人含义
- 行运行星与本命行星/四轴的相位关系
- 行运行星过宫（进入本命第几宫）
- 逆行周期对个人的影响（阴影期/逆行/留/恢复/后阴影）
- 多次精确相位的完整周期
- 支持、压力和整合
- 个人生活领域的活跃度变化
- 时间窗口：入相增强→精确峰值→出相收尾
- 行动建议：适合推进/调整/等待

### 2.3 不直接表达的内容

- 确定性事件预测（不能说"你会升职"）
- 行运结果的概率值（不能说"80%可能分手"）
- 与本命盘无关的纯天象描述（那是天象盘的职责）
- 医疗诊断或法律建议
- 投资建议或财务预测
- 吉凶评分或每日运势指数

### 2.4 与天象盘语料的边界

| 维度 | 天象盘 | 行运盘 |
|---|---|---|
| 关注层面 | 集体环境 | 个人影响 |
| 语料视角 | "集体环境中XX主题活跃" | "你近期XX领域更容易出现变化" |
| 行星关系 | 天象行星之间的相位 | 行运行星→本命行星/四轴/宫位 |
| 领域映射 | 八类集体领域（信息/关系/行动/规则等） | 十二宫位个人领域（自我/财富/沟通等） |
| 逆行含义 | 集体信息/交通/规则回顾 | 个人相关主题回顾和修正 |
| 建议方向 | 观察什么 | 做什么/注意什么/暂缓什么 |
| 联动方向 | 需叠加本命盘才能看个人 | 已有本命盘，直接看个人影响 |

## 三、行运行星语料

### 3.1 行运行星触发本命的核心表达

行运盘语料的核心变量是"行运行星 × 本命被触发点"的组合。行运行星决定变化类型，本命被触发点决定受影响的个人领域。

#### 行运行星→变化类型映射

| 行运行星 | 带来的变化类型 | 个人层面含义 |
|---|---|---|
| 太阳 | 关注点、活力方向、自我确认 | 自我认知、个人目标、精力投入方向的变化 |
| 月亮 | 情绪节奏、安全感需求、日常生活 | 情绪波动、家庭和居住、日常习惯的变化 |
| 水星 | 信息、沟通、思维、交通 | 沟通方式、学习、信息处理、短途出行的变化 |
| 金星 | 关系、价值、财务、审美 | 亲密关系、金钱收支、审美偏好的变化 |
| 火星 | 行动、冲突、精力、性 | 行动节奏、竞争关系、身体精力、冲动倾向的变化 |
| 木星 | 扩展、机会、信念、过度 | 成长空间、机遇、过度扩张、信念系统的变化 |
| 土星 | 收缩、责任、限制、结构 | 责任压力、时间限制、结构重组、长期建设的变化 |
| 天王星 | 突变、自由、突破、脱离 | 突发变化、打破常规、独立意识、技术突破的影响 |
| 海王星 | 模糊、理想、迷惑、灵性 | 边界模糊、理想化、迷惑与澄清、灵性体验的影响 |
| 冥王星 | 权力、转化、危机、重生 | 深层转化、权力关系、危机与重建、控制议题的影响 |

#### 本命被触发点→个人领域映射

| 被触发点 | 个人领域 | 触发含义 |
|---|---|---|
| 太阳 | 身份认同、核心自我、人生方向 | 自我认知和方向感被激活或被挑战 |
| 月亮 | 情感需求、安全感、家庭、日常 | 情绪节奏和安全感被触发 |
| 水星 | 思维方式、沟通、学习 | 思考和沟通模式被激活或被打断 |
| 金星 | 关系标准、审美、金钱 | 关系和价值判断被触动 |
| 火星 | 行动方式、竞争、性 | 行动冲动和竞争态势被激活 |
| 木星 | 信念、扩张、机遇 | 成长方向和机会窗口被打开或被压缩 |
| 土星 | 责任、限制、长期结构 | 责任和结构压力被加码或被重组 |
| 天王星 | 独立、突变、反叛 | 突变力量或独立意识被激发 |
| 海王星 | 理想、迷惑、灵性 | 灵感或迷惑被激活，边界感变化 |
| 冥王星 | 控制、转化、深层 | 深层转化的力量被启动 |
| 上升点 | 个人形象、自我呈现、身体 | 个人形象和自我认知出现变化信号 |
| 下降点 | 关系、合作、伴侣 | 一对一关系和合作模式受到触发 |
| 天顶 | 事业、社会角色、长期目标 | 事业方向和社会角色出现变化 |
| 天底 | 家庭、根基、内在安全感 | 家庭和内在根基出现变动 |

### 3.2 行运行星个人影响语料

每颗行运行星都有对应的个人影响语料，按"正向表现"和"压力表现"分别组织：

| 海王星 | 灵感和直觉增强，艺术感知力提升 | 模糊和迷惑增加，边界感下降 |
| 冥王星 | 深层洞察力和转化勇气 | 控制议题和权力冲突，深层不安 |

### 3.3 行运行星建议语料

| 行运行星 | 适合推进 | 需要调整 | 建议暂缓 |
|---|---|---|---|
| 太阳 | 自我表达、新方向启动 | 过度迎合他人 | 消极回避 |

| 火星 | 行动推进、竞争项目 | 冲动决策 | 挑起不必要冲突 |

## 四、行运相位语料

### 4.1 行运触发本命相位的语料结构

每个"行运行星 × 本命被触发点 × 相位类型"组合需要以下语料字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| 组合标题 | 8—18字概括 | 家庭与情绪节奏正在进入高活跃阶段 |
| 状态句 | 入相/精确/出相的当前状态 | 这一影响正在增强 |
| 主解释 | 40—120字说明影响 | 行运火星正在触发本命月亮，行动冲动与情绪安全感之间出现明显拉扯 |
| 正向句 | 支持/推动的表现 | 这一阶段有助于快速处理长期拖延的家庭问题 |
| 压力句 | 挑战/压力的表现 | 耐心下降时，容易把解决问题的急迫感带入亲近关系 |
| 建议句 | 具体可执行建议 | 适合明确分工、处理积压事务，避免在情绪高点扩大争论 |
| 时间句 | 时间窗口和阶段说明 | 当前处于入相阶段，影响仍在增强 |

### 4.2 相位类型→影响方向映射

| 相位类型 | 方向 | 个人层面含义 |
|---|---|---|
| 合相（0°） | 混合/激活 | 行运行星直接激活本命点，主题集中表现 |
| 六合（60°） | 支持 | 机会和成长空间，影响较温和 |
| 刑相（90°） | 压力 | 内在摩擦和调整需求，推动变革 |
| 拱相（120°） | 支持 | 自然流动和发展空间，天赋和资源被激活 |
| 冲相（180°） | 压力/整合 | 对立面激发，需要平衡和选择 |
| 半六合（30°） | 轻微调整 | 小调整和微调，影响较弱 |
| 梅花相（150°） | 微调/不适 | 轻微不适感，需要非直觉的调整 |

### 4.3 行运触发本命组合句（按方向分类）

#### 支持方向（六合、拱相）

> 行运【行星A】【六合/拱]本命【行星B】，当前有利的条件正在形成。【个人主题】有机会获得进展，【正向表现】更容易自然出现。

#### 压力方向（刑相、冲相）

> 行运【行星A】【刑/冲]本命【行星B】，当前调整需求正在增加。【个人主题】更容易出现摩擦或压力，【压力表现】需要特别注意。

#### 合相方向

> 行运【行星A】合本命【行星B】，【个人主题】正在进入集中表现期。这一触发既可能带来【正向表现】，也可能带来【压力表现】，取决于你当前的准备状态。

## 五、行运过宫语料

### 5.1 行运行星过本命宫位

行运行星进入本命第N宫时，对应个人生活领域会变得活跃：

| 宫位 | 领域 | 行运过宫语料模板 |
|---|---|---|
| 第1宫 | 自我、身体、个人形象 | 行运【行星】进入本命第1宫，自我认知和身体状态进入活跃期 |
| 第2宫 | 金钱、价值、资源 | 行运【行星】进入本命第2宫，财务和个人价值判断进入活跃期 |
| 第3宫 | 沟通、学习、近邻 | 行运【行星】进入本命第3宫，沟通和学习活动进入活跃期 |
| 第4宫 | 家庭、居住、根基 | 行运【行星】进入本命第4宫，家庭和居住环境进入活跃期 |
| 第5宫 | 创造、恋爱、娱乐 | 行运【行星】进入本命第5宫，创造力和恋爱活动进入活跃期 |
| 第6宫 | 工作、健康、日常 | 行运【行星】进入本命第6宫，日常工作和健康议题进入活跃期 |
| 第7宫 | 关系、合作、伴侣 | 行运【行星】进入本命第7宫，关系和合作模式进入活跃期 |
| 第8宫 | 共享资源、深层转化 | 行运【行星】进入本命第8宫，共享资源和深层议题进入活跃期 |
| 第9宫 | 远行、高等教育、信念 | 行运【行星】进入本命第9宫，远行和信念系统进入活跃期 |
| 第10宫 | 事业、公共角色、地位 | 行运【行星】进入本命第10宫，事业和公共角色进入活跃期 |
| 第11宫 | 社交、群体、愿望 | 行运【行星】进入本命第11宫，社交和群体活动进入活跃期 |
| 第12宫 | 内在、灵性、隐退 | 行运【行星】进入本命第12宫，内在世界和隐性议题进入活跃期 |

### 5.2 慢行星过宫的长期性

慢行星（土星/天王星/海王星/冥王星）过宫持续时间长，需要特别说明：

> 行运【慢行星】在本命第【N】宫停留约【X】年，【宫位领域】正在经历一段较长周期的调整。这一过程可能不是单一事件，而是该领域的持续重塑。

## 六、行运逆行周期语料

### 6.1 逆行周期的个人影响

| 阶段 | 时间范围 | 个人层面含义 | 语料 |
|---|---|---|---|
| 前阴影 | 逆行前约容许度区间 | 相关主题开始显现，日常中可能已经感到某些微妙变化 | 相关主题即将进入回顾和调整阶段，当前仍可推进，但建议保留调整空间 |
| 逆行中 | 逆行区间 | 旧问题可能再次出现，进展可能发生反复 | 相关主题进入回顾和调整阶段，旧问题可能再次出现，进展可能发生反复，更适合复盘、修正和补充 |
| 留点 | 逆行→顺行转换点 | 相关议题高度集中 | 相关主题处于高度集中状态，表面进展有限但内部压力正在积累 |
| 恢复顺行 | 顺行恢复后 | 反复状态开始结束 | 反复状态开始逐渐结束，原有问题有机会进入解决阶段 |
| 后阴影 | 顺行恢复后的容许度区间 | 修正结果进入实施 | 前期修正结果开始进入实施阶段，但需确认方向已稳定 |

### 6.2 逆行盘型特殊规则

- 水星逆行：沟通、签署、交通、电子设备相关议题更容易出现反复
- 金星逆行：关系、金钱、审美相关议题更容易重新评估
- 火星逆行：行动方向、竞争、身体精力更容易出现阻滞和重新校准
- 木星逆行：信念、扩展方向更容易重新审视
- 土星逆行：责任、长期结构更容易面临回顾和压力测试
- 外行星逆行（天王/海王/冥王）：深层变化方向更容易出现回顾期，个人感受较间接

## 十三、表达红线

以下表达方式仍然禁止：

- 天象描述代替个人影响："当前土星和冥王星形成刑相"（应说"行运土星正在触发你的本命冥王星，……"）
- 过度笼统："这段时间要注意"
- 单一时间点："3月15日会发生XX"（应给时间窗口）
- 忽略入相/出相：只写精确当天
- 把压力行运写成灾难
- 把支持行运写成保证成功
- 无依据的确定性预测："你下个月会升职"（见趋势条件句章节的合规写法）
- 伪概率值："80%可能遇到贵人"（见敏感度指标章节的合规写法）

以下表达方式纳入可控框架（详见第十六—十九章）：

| 原始形态 | 合规形态 | 核心规则 |
|---|---|---|
| 吉凶评分 | 日活跃度指数 | 必须可追溯到行运信号计算，点击可查看底层拆解 |
| 事件概率 | 敏感度指标 | 表达的是象征性影响集中度，不是事件发生概率 |
| 确定性预测 | 趋势条件句 | 必须带条件前提，不写无条件的必然结果 |
| 情绪热力图 | 行运强度日历 | 每日强度值基于行运信号加权计算 |

## 十四、生成规则

### 14.1 行运信号优先级

```text
行运慢行星与本命个人行星精确相位
> 行运行星触发本命四轴
> 多个行运信号同时共振
> 行运行星换座（进入新星座）
> 行运行星过宫（进入新宫位）
> 行运行星逆行/留/恢复顺行
> 快行星（月亮/水星/金星）短期触发
```

### 14.2 各速度层级行星的语料角色

| 层级 | 行星 | 语料特征 | 影响时长 |
|---|---|---|---|
| 慢行星 | 土星、木星、天王星、海王星、冥王星 | 长期背景、结构性变化 | 1—3 年周期 |
| 中速行星 | 火星 | 阶段性推动 | 2—6 个月周期 |
| 快行星 | 太阳、水星、金星、月亮 | 短期触发 | 数天到数周 |

### 14.3 信号评分

```text
transit_signal_score =
  transit_planet_weight
  × natal_point_weight
  × aspect_weight
  × exactness_weight
  × phase_weight
  × resonance_weight
```

- `transit_planet_weight`：慢行星权重更高
- `natal_point_weight`：四轴 > 个人行星 > 外行星
- `aspect_weight`：合/刑/冲 > 拱 > 六合
- `exactness_weight`：越接近精确权重越高
- `phase_weight`：入相 > 出相
- `resonance_weight`：多个信号指向同一主题时共振加成

分数只用于排序，不表示事件概率。

## 十五、日活跃度指数语料

### 15.1 指数定义

日活跃度指数（Daily Activity Index）是当天行运信号强度的综合反映，0—100 分，每天更新。

核心原则：**指数反映的是行运信号的集中程度，不是运气好坏。高分=行运信号密集，低分=行运信号稀疏。高分既可能是大量机会同时出现，也可能是大量压力同时集中。**

### 15.2 计算规则

```text
daily_index =
  Σ(transit_signal_score × proximity_weight)
  / theoretical_max
  × 100
```

- `transit_signal_score`：当日各行运信号的评分（见十四章）
- `proximity_weight`：越接近精确相位权重越高（当天精确=1.0，前一天=0.8，容许度边缘=0.3）
- `theoretical_max`：理论最高分（用于归一化到 0—100）

支持行运和压力行运都计入指数，不区分方向。

### 15.3 指数等级与语料

| 等级 | 分数范围 | 语料 | 视觉建议 |
|---|---|---|---|
| 静默 | 0—20 | 当前行运信号较少，个人状态以延续为主 | 深蓝/灰色，低亮度 |
| 轻度 | 21—40 | 部分行运信号开始显现，日常节奏出现微调 | 浅蓝色 |
| 活跃 | 41—60 | 多个行运信号同时活跃，部分领域出现明显调整 | 绿色/蓝绿色 |
| 高活跃 | 61—80 | 行运信号集中，个人体验可能出现较明显的变化 | 橙色 |
| 密集 | 81—100 | 行运极为密集，高强度信号集中出现，个人体验处于重要调整期 | 红色/橙红色 |

### 15.4 指数拆解

用户点击指数时，必须能查看底层拆解：

```text
今日活跃度指数：68/100（高活跃）

构成：
  压力信号 42分  行运火星刑本命月亮（精确）
  支持信号 18分  行运木星拱本命金星（入相）
  背景信号 8分   行运土星合本命天顶（出相）
```

### 15.5 方向子指数

除总指数外，额外提供两个方向子指数：

- **推动指数**：支持行运信号的总贡献
- **调整指数**：压力行运信号的总贡献

两个子指数之和不一定等于总指数（中性信号不归入任一方向）。

语料：推动指数【X】/调整指数【Y】— 当前调整需求【略高于/接近/略低于】推进条件。

## 十六、敏感度指标语料

### 16.1 指标定义

敏感度指标（Sensitivity Indicator）表示某个个人领域当前被行运激活的程度，0—100%。

核心原则：**敏感度不等于事件概率。高敏感度=该领域当前被行运信号密集激活，更容易出现相关体验；低敏感度=该领域当前行运信号较少。**

### 16.2 计算规则

```text
sensitivity =
  该领域的行运信号总分数
  / 理论最高分数
  × 100%
```

按十二宫位分别计算。

### 16.3 敏感度等级与语料

| 等级 | 范围 | 语料 | 视觉 |
|---|---|---|---|
| 低敏感 | 0—25% | 该领域当前行运信号较少，以日常节奏为主 | 灰色/浅色 |
| 中敏感 | 26—50% | 该领域开始出现行运激活信号 | 蓝色 |
| 高敏感 | 51—75% | 该领域行运激活程度较高，相关体验更容易出现 | 橙色 |
| 极敏感 | 76—100% | 该领域行运高度集中，相关体验可能出现明显变化 | 红色 |

### 16.4 敏感度表达规则

合规写法：
- "当前【关系领域】敏感度 72%"— 表示该领域行运激活程度高
- "敏感度较高的领域更容易出现相关体验"

不合规写法：
- "72%可能分手" — 敏感度不是事件概率
- "关系运势72分" — 不叫运势，叫敏感度

## 十七、趋势条件句语料

### 17.1 句式结构

趋势条件句 = **条件前提** + **趋势描述** + **不保证声明**

```text
如果【条件前提】，当前行运更容易推动【趋势描述】。
但行运只反映象征性影响的集中度，实际结果取决于个人选择和外部条件。
```

### 17.2 条件前提分类

| 前提类型 | 说明 | 示例 |
|---|---|---|
| 准备前提 | 如果你在相关方向已有准备 | "如果你近期已在准备职业调整" |
| 存在前提 | 如果现实中已存在相关问题 | "如果关系中已存在未解决的分歧" |
| 行动前提 | 如果你采取相关行动 | "如果主动推进沟通和协商" |
| 感知前提 | 如果你注意到相关信号 | "如果感到事业方向出现松动迹象" |

### 17.3 趋势描述分类

| 趋势类型 | 说明 | 示例 |
|---|---|---|
| 推动趋势 | 行运支持方向更容易出现的结果 | "已有准备的方向更容易获得推进" |
| 调整趋势 | 行运压力方向可能带来的变化 | "旧模式更容易被打破，调整需求增加" |
| 显化趋势 | 行运触发更容易让已有状态明朗化 | "之前模糊的问题更容易浮出表面" |
| 回顾趋势 | 逆行期更容易出现的回顾和修正 | "之前处理的结果更容易需要重新审视" |

### 17.4 趋势条件句示例

**事业方向**：
> 如果你近期已在考虑职业调整，当前行运土星触发本命天顶，更容易推动这一方向进入明确的处理阶段。但行运只反映象征性影响的集中度，实际结果取决于个人选择和外部条件。

**关系领域**：
> 如果关系中已存在未解决的分歧，行运金星逆行期间更容易让这些问题再次浮现。适合重新审视，不适合强制推进重大决定。

**财务方向**：
> 如果当前有投资或支出计划，行运木星拱本命金星期间扩展空间增加，但需注意木星也容易带来过度乐观的判断。

### 17.5 禁止的无条件预测

- "你下个月会升职" — 无条件，且确定性结果
- "近期一定会有感情变化" — 无条件，且确定性结果
- "这周会遇到贵人" — 无条件，且具体事件预测

## 十八、行运强度日历语料

### 18.1 日历定义

行运强度日历（Transit Intensity Calendar）是30天日历视图，每天按行运信号总强度着色。

### 18.2 每日强度计算

```text
daily_intensity =
  Σ(当日活跃行运信号分数 × 当日接近度权重)
  / theoretical_max
  × 100
```

与日活跃度指数使用相同的计算方法，但日历额外标注：
- 当日有精确相位 → 用圆点标记
- 当日有行星换座/过宫 → 用箭头标记
- 当日有逆行/顺行转换 → 用闪电标记

### 18.3 日历着色规则

| 强度范围 | 着色 | 说明 |
|---|---|---|
| 0—20 | 深蓝底 | 静默日，行运信号稀疏 |
| 21—40 | 浅蓝底 | 轻度日，部分信号微调 |
| 41—60 | 蓝绿底 | 活跃日，多个信号同时活跃 |
| 61—80 | 橙色底 | 高活跃日，体验可能出现较明显变化 |
| 81—100 | 红橙底 | 密集日，高强度信号集中 |

### 18.4 日历交互

> 二阶段：点击日历中的某一天，展开当日行运事件列表和活跃度指数。

一阶段：日历只做展示，不响应点击。鼠标悬停显示当日指数数值。

### 18.5 日历上方总览

日历顶部显示当月概览：

- 本月最高强度日：X日（强度【等级】）
- 本月最平稳时段：X日—Y日
- 本月关键转折点：X日（行运【行星】【相位】本命【点位】精确）

### 标题

### 20.3 文字层设计原则

- 视觉为主，文字辅助——图表先说话，文字再解释

- card_detail 不是重复图表，而是解释"这意味着什么"
- card_summary 不写结论性预测，只写当前状态概括
- card_detail 补充当前阶段、注意事项和建议方向
- 原有文字内容保留，不过度增加
