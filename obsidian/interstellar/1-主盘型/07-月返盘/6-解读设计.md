# 月返盘 · 解读设计

> 盘型定位：看清未来一个月的情绪天气、每周节奏和现实生活焦点
> 核心问题：这个月整体是什么气候，哪一周最忙，哪些领域最敏感，何时推进或休整
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

天气、周节拍、月相、蜂巢、潮汐、看板；强调生活管理与周度节奏

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│  🌙 卡片标题                    ▸ 详情│
│┌────────────────────────────────────┐│
││         [专属视觉图表区]            ││
││   · 数据标签   · 状态指示   · 时间  ││
││   · 等级/方向  · 对比变化    · 来源  ││
│└────────────────────────────────────┘│
│──────────────────────────────────────│
│ 一句话摘要（20—30字，始终可见）        │
│ ▸ 展开详细解读（默认收起）            │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：月度天气指数

- **视觉结构**：天气卡 + 四周节拍条；显示月度活跃度、情绪湿度、行动能见度和关系潮位
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│  ⛅ 本月：多云转晴   温度23°  风力3级  │
│──────────────────────────────────────│
│  主指数  72            ▲ +8 vs上月   │
│  ┌─────────────┬────────────────────┐│
│  │ 情绪湿度 68% │ 行动能见度 74%     ││
│  │ ████░░ 温和  │ █████░ 清晰        ││
│  └─────────────┴────────────────────┘│
│  主导方向：事务密集 → 后半月转顺       │
│  信号Top3：①月返上升 ②月亮过宫       │
│           ③主星入角                   │
│  ▸ 点击指标查看底层信号详情           │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：本月主题天气图

### 目标

这个月整体氛围怎样。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主天气 | 晴/多云/闷热/大风 |
| 情绪湿度 | 情绪敏感度 |
| 行动能见度 | 行动清晰度 |
| 风向 | 主题变化方向 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│  卡片J · 本月行动窗口              ▸ │
│──────────────────────────────────────│
│  推进窗  8/3—8/9   ███████   ★最佳  │
│  调整窗  8/12—8/16     ████          │
│  观察窗  8/22—8/25         ░░░░      │
│  ──┬────────┬────────┬──────────    │
│    │推进   │调整    │观察         │
│    │已方向  │沟通排期│等待反馈     │
│  ──┴────────┴────────┴──────────    │
│  条件：推进窗成立前提为W1无阻力      │
│  ▸ 点击窗口条查看任务类型建议       │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 本月整体氛围偏【状态】，主线集中在【主题】。 |
| 展开解读 | 用天气隐喻解释月返基调，并明确天气只是状态语言，不是吉凶判断。 |

### 展开解读示例

> 本月整体多云转晴，前半月事务密集、情绪湿度偏高，后半月行动能见度提升。主线集中在关系沟通和工作排期。

### 交互与动效

- 天气图标轻微动态；数值按月返周期渐变。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 月返上升、月亮、主星、角宫、月度评分。
