# 命名规范

> 统一命名规则，避免歧义和风格不一致。

---

## 文件命名

| 位置 | 规则 | 示例 |
|---|---|---|
| `components/` 下的组件文件 | kebab-case，与组件名对应 | `secondary-progressions-workspace.tsx` |
| `lib/insight/` 下的数据构建文件 | 盘型英文名，单数 | `secondary.ts` |
| `lib/insight/` 下的语料数据文件 | `{盘型名}-corpus.ts` | `secondary-corpus.ts` |
| `lib/hooks/` 下的自定义 hooks | `use-{功能描述}.ts` | `use-ai-analysis.ts` |
| `styles/` 下的 CSS 文件 | 盘型英文名 | `secondary.css` |
| 后端 `routers/` 下的路由文件 | 业务域名词，kebab-case | `natal-ai.py`（不使用 m1/m2 前缀） |

**禁止**：
- 文件名中出现盘型缩写混用（如 `sec.ts` 和 `secondary.ts` 并存）
- 文件名与导出的主类型/函数名不一致（如文件叫 `insight.ts` 但导出 `buildSecondary...`）

## 组件命名

| 规则 | 说明 | 示例 |
|---|---|---|
| PascalCase | 所有 React 组件 | `SecondaryProgressionsWorkspace` |
| 文件名 = 组件名 | 组件文件名与默认导出的组件名一致 | `comparison-wheel.tsx` → `ComparisonWheel` |
| 盘型前缀 | 非通用组件以盘型英文名开头 | `SecondaryCalculationPanel` |

**通用组件**（跨盘型复用）不加盘型前缀：`AspectGrid`、`NatalWheel`、`SharedAdvancedCalculationFields`。

## 函数命名

| 前缀 | 用途 | 示例 |
|---|---|---|
| `build` | 数据构建函数，输出类型化对象 | `buildSecondaryProgressionRightPanel` |
| `use` | React hooks | `useChartCalculation` |
| `trigger` | 用户操作触发的异步动作 | `triggerAiAnalysis` |
| `clone` | 深拷贝工具 | `cloneNatalSettings` |
| `identify` | 识别/判断函数 | `identifyTimingPreset` |
| `effective` | 计算有效值 | `effectivePointIds` |

**禁止**：
- `get` / `set` 前缀（与 getter/setter 混淆）
- 无前缀的动词（如 `calculate()`，应写明计算什么：`calculateSecondaryProgression`）

## CSS class 命名

| 规则 | 示例 |
|---|---|
| 通用布局类：功能描述 | `workbench-grid`、`ai-insight-panel`、`settings-panel` |
| 盘型专用类：`{盘型名}-{功能}` | `secondary-person-card`、`secondary-field-label` |
| 卡片/区块类：功能描述 | `insight-card-sp`（sp = secondary progression）、`instant-theme` |
| 状态类：`is-{状态}` 或 `has-{特征}` | `is-active`、`has-legend` |
| 禁止 | 驼峰 CSS class（`insightCardSp`）、单字母缩写（`sp-c`） |

## 类型命名

| 规则 | 示例 |
|---|---|
| 盘型专有类型以盘型名开头 | `SecondaryProgressionCard`、`SecondaryProgressionRightPanel` |
| 通用类型不加盘型前缀 | `ConsumerInsight`、`InterpretationSection` |
| Props 类型：`{组件名}Props` | `ComparisonWheelProps` |
| 后端 Pydantic 模型：PascalCase | `NatalAiPayload`、`NatalSnapshot` |
