## 4、结果解读

### 4.1 印占无独立"解析页"

**关键区别**：印占星盘**没有**西占那种点击"解析"按钮后进入的独立解析页面。印占的结果解读全部内嵌在计算面板的 **12个tab** 中，每个tab本身就是一种解读维度。

### 4.2 轮盘信息

#### 星盘风格

- **北印度棱形方盘**（默认）/ **南印度方形**（可在设置中切换）
- 宫内数字可切换含义：**代表星座** / 代表宫位
- 岁差显示：轮盘下方（如「Traditional Lahiri 23°51'19.991'」）

#### 轮盘标题

每个分盘/双盘模式有独立的轮盘标题：

| 分盘 | 标题示例 |
|------|---------|
| Rasi | 本命 |
| D9 | 婚姻、运气 |
| Mo | 月盘 |
| Bhava | 宫位盘 |
| Transit | 行运盘 |

#### 宫上升选择器

轮盘上方有「宫上升」选择器（12个选项：1~12宫上升，默认1宫上升），可切换以不同宫位为第1宫的转宫盘。

#### 映射交互（相映）

印占独有的轮盘交互：点击轮盘上的一颗行星A：
- **蓝色高亮**的宫 = 该星A可以映射的宫位（A对它们的相映）
- **红色高亮**的行星 = 反过来映射该星A的星体

映射（相映/映角/投掷）是单向的，不同于西占的相位是互相的。

### 4.4 各tab详细内容

#### ① 行星

10个星体（上升/太阳/月亮/火星/水星/木星/金星/土星/北交点/南交点），每行8列：
- **星体**：行星图标+名称缩写（如上升(As)、太阳(Su)）
- **黄道经度**：含星座（如「巨蟹 29°05'」）
- **速度**：顺/逆
- **宫位**：1~12宫
- **星宿**：27星宿之一（如柳宿、危宿、箕宿）
- **宿主**：星宿主宰星图标
- **pada**：1~4
- **指标**：Jamini指标星（Gk/Ak/Bk/Pk/Dk/Amk/Mk），仅7颗主星有

#### ② 虚星

11个Upagrahas虚点，两系列：

**Dhooma系列**（来自太阳）：Dhooma / Vyatipata / Parivesha / Indrachaapa / Upaketu

**Kala Velas系列**（化身行星影子之子）：Kaala / Mrityu / Artha Praharaka / Yama Ghantaka / Gulika / Maandi

列：名称/黄道经度/宫位/星宿/宿主/pada/父星（父星列部分虚点显示「—」，部分显示行星图标）

#### ③ 特殊点

9个Lagna系列特殊点 + 2个Yogi点：

**Lagna系列**：Bhava Lagna / Hora Lagna / Ghati Lagna / ViGhati Lagna / Pranapada Lagna / Sree Lagna / Indu Lagna / Varnada Lagna / Kunda

**Yogi系列**：Yogi Point / Avayogi Point

列：名称/黄道经度/宫位/星宿/宿主/pada（无父星列）

#### ④ 映射

12个Arudha（映射宫），代表各宫主宰星映射出的宫：

AL / A2 / A3 / A4 / A5 / A6 / A7 / A8 / A9 / A10 / A11 / UL

- **AL**（Arudha Lagna）：外向外表看到的你
- **UL**（Upapada Lagna）：伴侣相关的映射

列：名称/星座/宫（仅3列，结构最简洁）

#### ⑤ 八分点（Ashtakavarga）

矩阵表格，行=7星+上升+7星总计，列=1~12宫：

- **星座行**：各宫对应的星座缩写
- **上升行**：上升在各宫的八分点值
- **7星各行**：每颗星在各宫的八分点值
- **7星总计行**：7颗主星的合计值（不含上升）

#### ⑥ 星力（Shadbala）

3个子视图切换：**总表** / **Kaal** / **Sthan**

总表视图7颗主星，每行11列：
- **总分(Shad)**：总Shadbala分数（如410.03）
- **达标分**：最低要求分数
- **达标Rupa**：达标Rupa值
- **满足率**：如105.14%
- **差额**：如+20.03
- **位置(Sthan)** / **方向(Dig)** / **时间(Kaal)** / **运动(Chesht)** / **自然(Naisa)** / **凝视(Drik)**：6维分项分数

底部提示：「Shadbala已对照JHora，请注意岁差与分盘算法」

#### ⑦ 大运（Vimsottari Dasa）

主运/次运两级表格：
- **主**：大运行星图标
- **次**：次运行星图标
- **开始时间**：该期间起始日期

按大运期间从出生日期开始排列，覆盖一生。

底部标注：「采用 Vimsottari Dasa」

#### ⑧ 敌友

7×7行星敌友关系矩阵，5种关系：
- **大友** / **友** / **中立** / **敌** / **大敌**

行=主星（日/月/水/金/火/木/土），列=对星

底部提示：「复合敌友关系：大友、友、中立、敌、大敌」

#### ⑨ 瑜伽

Yoga组合列表，每行3列：
- **瑜伽**：Yoga名称（如BudhaAditya、Sunapha、RajaYogaGeneric等）
- **判定**：中文判定描述（如「太阳与水星同宫」「角宫主与三角宫主同宫」等）
- **含义**：中文含义解释（如「思维清晰、表达突出，学习与名望机会较多」）

示例Yoga：BudhaAditya / Sunapha / Veshi / Voshi / Ubhayachari / Yogakaraka / RajaYogaGeneric / Pasha / Mala / ArdhaChandra

#### ⑩ 宫

- **Cusp**：宫头度数
