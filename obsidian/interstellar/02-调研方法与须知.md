# 02 调研方法与须知

> 本文档总结爱占星竞品调研的完整操作流程、关键技术和踩过的坑。后续盘型调研按此步骤执行。

---

## 一、调研原则

1. **实测优先**：所有参数必须通过浏览器实际操作设置页确认，不能只看JS源码推断
2. **逐条记录**：每个参数的可选项、默认值必须完整列出，不能只写"和XX一样"
3. **预设值全量**：三体系（现代/古典/特殊）的预设值要写全，一样的地方也要写出来
4. **逐文档确认**：每完成一个盘型文档就输出一次确认
5. **不混入全局配置**：盘型文档只记录该盘型设置页上实际出现的参数，全局专业参数另行记录

## 二、工具与环境

### 2.1 浏览器
- 使用 Playwright 控制浏览器访问 `https://www.aizhanxing.com/astro-h5/`
- 需要先导航到主盘型页面，再通过点击切换盘型（直接URL导航不会触发Vue重渲染）

### 2.2 Vuex Store 访问
通过浏览器控制台执行JS读取Vuex store内部数据：

```js
const app = document.querySelector('#app').__vue_app__;
const store = app.config.globalProperties.$store;
const state = store.state;
// 盘型设置数据
const map = state.chartSettings.chartSettingMap;
```

**数据结构**：
- `chartSettingMap` 是一个对象，key为 chartName（如 `natal`、`transit`、`divisional12`）
- 每个盘型数据结构：`{ type: 0, list: [现代, 古典, 特殊] }`
- `list[0]` = 现代体系，`list[1]` = 古典体系，`list[2]` = 特殊体系
- 每个体系对象包含：
  - `zodiacTypeIndex` — 黄道制（0=Tropical, 1=Sidereal）
  - `sidModeIndex` — 岁差（0-10，仅Sidereal时有效）
  - `houseTypeIndex` — 宫制（0-14）
  - `orbsType` — 容许度类型（0=现代-相位, 1=古典-星光, 2=古典-星座）
  - `hasArabic` — 阿拉伯点开关
  - `planets` — 行星开关对象 `{ "Sun": { hidden: 0 }, ... }`
  - `aspects` — 相位对象 `{ "1": { hidden: 0, orb: 7, maxOrb: 12 }, ... }`
  - `orbsLight` — 星光容许度（⚠️ 内部计算数据，不在设置页显示）

### 2.3 设置页导航方法

**正确方法**（分两步）：
1. 先导航到 `https://www.aizhanxing.com/astro-h5/#/pages/charts/charts`
2. 点击目标盘型的tab标签，等待2秒让Vue完成渲染
3. 点击齿轮图标进入设置页

**错误方法**：直接用URL导航到设置页（如 `/#/pagesA/chart-setting/...?chartName=transit`），不会触发Vue组件重新渲染，导致看到的是上一个盘型的设置。

## 三、标准调研步骤（每个盘型）

### 步骤1：确认盘型基本信息
- chartName（Vuex key）
- 是否有单盘/双盘切换
- 设置页标题格式
- 计算器面板tab数量与名称

### 步骤2：Vuex Store 全量提取
通过JS一次性提取该盘型三个体系的全部参数数据。示例：
```js
const map = state.chartSettings.chartSettingMap;
const chart = map['natal']; // 替换为目标chartName
const systems = ['现代', '古典', '特殊'];
chart.list.forEach((s, i) => {
    console.log(`\n=== ${systems[i]} ===`);
    console.log('zodiacTypeIndex:', s.zodiacTypeIndex);
    console.log('sidModeIndex:', s.sidModeIndex);
    console.log('houseTypeIndex:', s.houseTypeIndex);
    console.log('orbsType:', s.orbsType);
    console.log('hasArabic:', s.hasArabic);
    console.log('planets:', JSON.stringify(s.planets));
    console.log('aspects:', JSON.stringify(s.aspects));
});
```

### 步骤3：设置页UI实测验证
Vuex数据能拿到"值"，但**可选项列表**必须通过UI实测确认：
- 点击黄道制下拉 → 记录实际显示的选项（不是全站合集！）
- 点击宫制下拉 → 记录实际显示的选项
- 点击岁差下拉（仅Sidereal时） → 记录全部选项
- 查看是否有该盘型独有的参数区域（如法达盘的算法区、小限盘的起点/方向）

### 步骤4：计算器面板实测
- 切换到计算器视图
- 逐个点击tab，记录每个tab的列结构和内容
- 注意空状态引导文案

### 步骤5：按标准格式编写文档
按下方"文档格式标准"编写。

## 四、文档格式标准

每个盘型文档必须包含以下章节（按顺序）：

### 一、参数设置

**固定章节结构**（带编号）：
- `1.1` 黄道制（zodiacTypeIndex）— 含可选项表 + 三体系预设值
- `1.2` 宫制（houseTypeIndex）— 含可选项表 + 三体系预设值
- `1.3` 相位容许度类型（orbsType）— 含orbsLight计算说明
- `1.4` 行星开关（10个）— 逐条列出
- `1.5` 虚点开关（13个）— 逐条列出
- `1.6` 小行星开关（9个）— 逐条列出
- `1.7` 汉堡虚星开关（8个）— 逐条列出
- `1.8` 相位容许度（10个，逐条）— A族/B族分开
- `1.9` 相位展示（10个）
- `1.10` 阿拉伯点 — 含开关 + 选择页面
- `1.11` 全局设置 — 含恒星/相位线/行星颜色/界主星等子项
  - 如果有单盘/双盘：`1.12` 单盘 vs 双盘预设差异总结

**如果有盘型独有参数**（如法达盘的算法区），放在 `1.1` 之前作为专属参数。

### 二、计算结果（计算器面板）
- 列出tab数量
- 逐tab记录内容结构

### 三、页面其他参数
- 单盘/双盘切换
- 宫位制+黄道+体系标签
- 氛围文案
- 其他UI元素

### 四、数据来源声明
```
> 数据来源：Vuex store 实测 + 浏览器设置页UI实测（日期），说明实测了哪些
```

## 五、重点问题标记（⚠️ 踩过的坑）

### ⚠️ 坑1：黄道制可选项不是全站合集
**问题**：之前文档列了22种黄道制选项（从JS源码提取的全站合集），但实测每个盘型设置页只有2种。

**正确做法**：
- 每个盘型必须实测该盘型设置页黄道制下拉实际显示的选项
- 西占盘型实测为2种：Tropical回归黄道(index=0)、Sidereal恒星黄道(index=1)
- 印占星盘独立体系，黄道固定为恒星黄道

### ⚠️ 坑2：恒星黄道子参数只有一个"岁差"
**问题**：之前文档写了 `sidModeIndex`（恒星黄道模式）+ `ayanT0`（岁差校正值）两个子参数。实测发现设置页只有一个子参数"岁差"（sidModeIndex），有11个选项。`ayanT0` 在UI上不存在。

**正确格式**：
```
**恒星黄道子参数**（仅当 zodiacTypeIndex=1 时出现）：

| 参数 | 可选项数 | 默认值 | Vuex key |
|------|---------|--------|----------|
| 岁差 (sidModeIndex) | 11 | 0（FaganBradley西占默认） | sidModeIndex |

| index | 选项 |
|-------|------|
| 0 | FaganBradley西占默认 |
| 1 | Lahiri印占默认 |
| 2 | Deluce |
| 3 | Raman |
| 4 | Ushashashi |
| 5 | Krishnamurti |
| 6 | DjwhalKhul |
```

### ⚠️ 坑5：星光容许度（orbsLight）不在设置页上
**问题**：之前文档把 orbsLight 列为设置页的一个参数章节。

**事实**：orbsLight 是Vuex store内部计算数据，不在设置页UI上显示，用户无法在UI上看到或修改它。

**正确做法**：不作为独立章节，而是作为 orbsType（容许度类型）章节的补充说明写入。说明文字如下：

> **orbsType=1（古典-星光）时的内部计算逻辑**：
> 当选择"古典-星光"时，系统不使用按相位分配的容许度（A族/B族），而是改用按星体分配的星光容许度（orbsLight）。该数据存储在Vuex内部，不在设置页上显示。判断两个星体是否形成相位时，取两个星体各自的 orbsLight 值中较小的那个作为容许度。
>
> | 星体 | orbsLight |
> |------|-----------|
> | 太阳 | 15° |
> | 月亮 | 12° |
> | 水星 | 7° |
> | 金星 | 7° |
> | 火星 | 8° |
> | 木星 | 9° |
> | 土星 | 9° |
> | 天王星 | 5° |
> | 海王星 | 5° |
> | 冥王星 | 5° |
> | 北交点 | 5° |
> | 上升 | 5° |
> | 中天 | 5° |
> | 其他 | 5° |

### ⚠️ 坑6：容许度族（A族/B族）规律
**A族**（本命盘级，maxOrb统一12°）：
- 合相7°, 对冲6°, 三合6°, 刑克6°, 六合6°, 十二分3°, 辅十二分3°, 八分3°, 辅八分3°, 五分3°

**B族**（推运盘级，maxOrb: 1-5为8°, 6-10为5°）：
- 合相2°, 其余全部1°

### ⚠️ 坑7：三体系预设规律
| 体系 | orbsType | houseTypeIndex | 天海冥 | Fortune |
|------|----------|---------------|--------|---------|
| 现代 | 0（现代-相位） | 0（Placidus） | 显示 | 显示 |
| 古典 | 1（古典-星光） | 4（Alcabitus） | 隐藏 | 显示 |
| 特殊 | 0（现代-相位） | 2（Whole整宫） | 隐藏 | 显示 |

### ⚠️ 坑8：不要把全局配置混入盘型文档
盘型文档只记录该盘型设置页上实际出现的参数。"更多专业设置"页面（路由 `/pagesA/settings/params`）的全站通用参数记录在 [[04-全局专业参数设置]] 中，盘型文档只需引用。

### ⚠️ 坑9：直接URL导航不触发Vue重渲染
设置页通过Vue Router的hash路由访问。直接在地址栏输入设置页URL不会触发组件重新渲染，会显示上一个盘型的设置。必须先回到主盘型页面，点击盘型tab，等渲染完成后再进设置页。

### ⚠️ 坑10：双盘chartName与单盘不同
有单盘/双盘切换的盘型，单盘和双盘使用不同的chartName，设置独立保存：
- 12分盘：单盘 `divisional12`，双盘 `divisional12Compare`
- 13分盘：单盘 `divisional13`，双盘 `divisional13Compare`
- 龙首盘：单盘 `draconic`，双盘 `draconicCompare`
- 次限盘：单盘 `secondaryProgression`，双盘 `secondaryProgressionCompare`
- 三限盘：单盘 `tertiaryProgression`，双盘 `tertiaryProgressionCompare`
- 日返盘：单盘 `solarReturn`，双盘 `solarReturnCompare`
- 月返盘：单盘 `lunarReturn`，双盘 `lunarReturnCompare`
- 泛音盘：单盘 `harmonic`，双盘 `harmonicCompare`

### ⚠️ 坑11：阿拉伯点选择页面需要实测
设置页"阿拉伯点"区域有 toggle 开关（控制 hasArabic）+ "显示更多阿拉伯点"文字链接。点击链接进入阿拉伯点选择页面（路由 `/pagesB/arabic-select/arabic-select`），页面分"系统"和"自定义"两个区域，系统区域有26个阿拉伯点，每个有toggle开关默认关闭。26个阿拉伯点的名称和计算公式需要逐个记录。

### ⚠️ 坑12：orbsType有3种但常用2种
| index | 选项 | 使用场景 |
|-------|------|---------|
| 0 | 现代-相位 | 现代体系、特殊体系 |
| 1 | 古典-星光 | 古典体系 |
| 2 | 古典-星座 | 未被三体系预设使用，但可手动选择 |
