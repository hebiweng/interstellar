## 3、计算面板

轮盘左上角 列表/计算器 两图标切换。**本命盘为 13 个 tab**。

### Tab 总览

| Tab | 名称 | 内容结构 |
|-----|------|---------|
| ① | 特征 | 互容接纳、映点/反映点、紧要度数、擢升度数、同度、度数排序 |
| ② | 行星 | 17列宽表：星体/黄经/落宫/主宰/庙/旺/三分/界/面/陷/弱/单度/分数/速度·均速(得时)/黄纬/赤经/赤纬 |
| ③ | 宫位 | 宫位/宫头度数/本垣/曜升/宫神星（Almuten） |
| ④ | 法达 | 主运/次运/起始日期 多列表格 |
| ⑤ | 小限 | 年/宫/主星 多列表格 |
| ⑥ | 阿拉伯点 | 星体/星座度数/宫位，28个阿拉伯点全量 |
| ⑦ | 恒星 | 星体/度数/宫位/合相；空状态引导去设置开启 |
| ⑧ | 福点 | 福点黄道释放（ZR from Fortune）L1/L2 期间 |
| ⑨ | 精神点 | 精神点黄道释放（ZR from Spirit）L1/L2 期间 |
| ⑩ | 映点 | 星体/自身/映点/反映点，全部星体含四轴 |
| ⑪ | 特殊度数 | 擢升/深陷/财富卓越/亮/烟朦胧/暗 六类度数逐条标注 |
| ⑫ | 光线 | 筛选器「光线:10主星」「围攻:相位容许度」 |
| ⑬ | 中点 | 筛选器「中点:6基础星体」「相位:全部」「容许度:1°」 |

### 独有 tab 说明

其中 ④法达、⑤小限、⑧福点、⑨精神点 为本命盘独有的时间主星/应期表 tab，其余 9 个 tab 与次限盘/12分盘等共有。

### 各 tab 详细内容

#### ① 特征

显示当前星盘的互容接纳关系和特殊度数信息：
- 互容接纳（标注本垣/曜升/三分/界/十度等尊贵力量）
- 互容（仅互容无接纳）
- 接纳（单向）
- 映点/反映点（标注度数差）
- 紧要度数（标注度数和星座类型）
- 擢升度数（标注度数和偏差值）
- 同度（不同星体同度数）
- 度数排序

底部标注使用界限类型（如"埃及界"）。

底部无设置链接。

#### ② 行星

17列宽表，每个星体一行：星体 / 黄经 / 落宫 / 主宰 / 庙 / 旺 / 三分 / 界 / 面 / 陷 / 弱 / 单度 / 分数 / 速度·均速(得时) / 黄纬 / 赤经 / 赤纬

底部无设置链接。

#### ③ 宫位

宫位 / 宫头度数 / 本垣 / 曜升 / 宫神星（Almuten）

底部无设置链接。

#### ④ 法达

主运/次运/起始日期 多列表格，按法达星限排列。

底部无设置链接。

#### ⑤ 小限

年/宫/主星 多列表格，按年龄排列。

底部有设置链接：「当前小限起点：下降，年小限：自然年，可在小限盘或**专业设置**处进行设置。」

#### ⑥ 阿拉伯点

28个阿拉伯点全量列表：福点/精神点/基础点/擢升点/爱神点/必需点/勇气点/胜利点/复仇点/物质点/资产点/婚姻点/男婚姻点/女婚姻点/离婚点/儿子点/女儿点/父亲点/母亲点/信仰点/手足点/爱情点/继承点/疾病点/背叛点/游戏点/危难点/死亡点

每点显示：星体/星座度数/宫位

底部无设置链接（有引导文案「增加更多阿拉伯点，可使用自定义阿拉伯点。」，非设置链接）。

#### ⑦ 恒星

星体/度数/宫位/合相。若恒星开关未开启，显示空状态引导去设置开启。

底部有设置链接：「恒星合相容许度在**专业设置**处进行设置。」

#### ⑧ 福点

福点黄道释放（ZR from Fortune）L1/L2 期间表格。

底部无设置链接。

#### ⑨ 精神点

精神点黄道释放（ZR from Spirit）L1/L2 期间表格。

底部无设置链接。

#### ⑩ 映点

星体/自身/映点/反映点，全部星体含四轴。

底部有设置链接：「消除岁差(恒星黄道)：未开启 / 映点轴：90.00°，去**设置**。」（显示当前映点相关参数状态并引导去设置修改）

#### ⑪ 特殊度数

六类度数逐条标注：擢升 / 深陷 / 财富卓越 / 亮 / 烟朦胧 / 暗

底部无设置链接。

#### ⑫ 光线

两个下拉筛选器：
- **光线**：当前值「10主星」
- **围攻**：当前值「相位容许度」

内容显示各星体被哪些星体围攻，格式如「水星(双鱼 11°38')被木星(60°)和太阳(0°)围攻」；还有「把光线从X向Y传递」「从X、Y收集光线」等结果。

底部无设置链接。

#### ⑬ 中点

三个下拉筛选器：
- **中点**：当前值「6基础星体」
- **相位**：当前值「全部」
- **容许度**：当前值「1°」
