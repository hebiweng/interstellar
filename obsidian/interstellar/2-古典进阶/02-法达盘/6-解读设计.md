# 法达盘 · 解读设计

> 盘型定位：看清人生阶段由哪颗行星掌舵，主运与辅运如何共同塑造时期语气
> 核心问题：当前是谁主导阶段，阶段进度如何，主辅星怎样合奏，何时换班
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

王座、宫廷、丝带、管辖区、交接门；强调阶段主宰与换班逻辑

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                              │
│ [专属视觉图表]                        │
│ 数据标签 / 状态 / 时间窗口            │
│ ────────────────────────────────── │
│ 一句话摘要（20—30字）                 │
│ 展开详细解读 ▸                        │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：主运阶段指数

- **视觉结构**：主运王座 + 阶段进度环；显示主运星、辅运星、当前进度、阶段语气和交接倒计时
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│    ♄ 土星王座期     指数 62/100      │
│  ╭══════════════════════════════╮   │
│  ║ ▰▰▰▰▰▰▰▰▰▰▰▰▰▰▱▱  62%   ║   │
│  ╰══════════════════════════════╯   │
│ 主旋律：责任·结构·长期建设           │
│ ┌──────────────┬───────────────┐  │
│ │密度 78 ██████│清晰 54 ████   │  │
│ ├──────────────┼───────────────┤  │
│ │趋势 ↗ +6     │倒计时 2y3m    │  │
│ └──────────────┴───────────────┘  │
│ 信号拆解 TOP3                        │
│① ♄落7宫 ② ♀合相 ③ ♄守10宫 [▸展开] │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：当前主运王座

### 目标

当前阶段由哪颗行星主导。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主运星 | 当前主宰 |
| 阶段进度 | 已走百分比 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│          ♄ 当前主运王座               │

│       ║ 土星·王座期   ║   62%       │
│       ╰══════════════╝              │
│  阶段 2025.03 ─────── 2028.09     │
│        ▰▰▰▰▰▰▰▰▰▰▱▱▱▱▱▱         │
│ 主旋律：责任·结构·长期建设          │
│ 本命：♑7宫18° 守护10·11宫         │
│ ────────────────────────────────  │
│ 一句话摘要 ▸                        │
│ [点击] 展开详细解读                  │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 你正处在【行星】主运期，阶段主旋律是【主题】。 |
| 展开解读 | 解释主运星的时代气质，并结合本命位置说明如何落地。 |

### 展开解读示例

> 当前为土星主运期，主旋律是责任、结构和长期建设。土星位于本命第7宫，因此这段时期的成长会大量通过合作、承诺和边界体现。

### 交互与动效

- 王座从暗到亮；进度环缓慢填充。
- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 法达主运序列、当前日期、本命主运星位置。
