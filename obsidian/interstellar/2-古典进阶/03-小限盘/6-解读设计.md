# 小限盘 · 解读设计

> 盘型定位：看清每一岁轮到哪一宫、哪颗时间主星当班，以及年度主题如何落地
> 核心问题：今年轮到哪个生活领域，时间主星如何把主题带到现实，哪些月份和触发器会放大它
> 设计版本：V2.0（颗粒度对齐版）
> 目标平台：iOS App

---

## 〇、平台设计原则

### 0.1 视觉语言

轮值、控制台、路由线、房间、接力、记分板；强调年度宫位当班与现实落点

### 0.2 统一卡片结构

每张卡片统一采用 **视觉图表区 + 一句话摘要 + 展开解读 + 数据来源 + 交互/动效** 五层结构。

```text
┌──────────────────────────────────────┐
│ 卡片标题                              │
│ [专属视觉图表]                        │
│ 数据标签 / 状态 / 时间窗口            │
│ ────────────────────────────────── │
│ 一句话摘要（20—30字）                 │
│ 展开详细解读 ▸                        │
└──────────────────────────────────────┘
```

### 0.3 文字层规范

| 层级 | 字数 | 默认状态 | 作用 |
|---|---:|---|---|
| 一句话摘要 | 20—30字 | 始终可见 | 独立传达本卡核心结论 |
| 展开解读 | 90—140字 | 默认收起 | 解释视觉含义、当前状态和注意事项 |
| 数据标签 | 2—12字 | 始终可见 | 说明等级、时间、方向、来源 |

## 一、顶部固定区：年宫激活指数

- **视觉结构**：12宫轮值盘 + 时间主星控制台；显示今年宫位、主星、主星状态、年度主题强度
- **显示内容**：0—100综合指数、等级标签、主导方向、与上一周期对比、底层信号前3项。
- **边界**：指数表示信号集中度和主题清晰度，不表示事件概率或好运程度。
- **动效**：进入页面时从0平滑增长到目标值；主导方向使用轻微呼吸动画，不使用持续闪烁。

### 视觉元素

| 视觉元素 | 说明 |
|---|---|
| 主指数 | 0—100，显示当前主题密度或结构清晰度 |
| 双层子指标 | 将主指数拆为两种核心方向，避免单一分数失真 |
| 趋势箭头 | 与上一日、上一周或上一阶段比较 |
| 信号拆解 | 显示贡献最高的3项底层信号 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ 年宫激活指数              72 高活跃 ↑  │
│ ─────────────────────────────────── │
│      11宫  [10宫◄]  9宫              │
│   12宫    ● 年宫轮     8宫           │
│      1宫        7宫                  │
│        2宫 ··· 6宫                   │
│ ─────────────────────────────────── │
│ 主星强度 ████████░░ 78  ↑5           │
│ 主题密度 ██████░░░░ 62  ↑2           │
│ ─────────────────────────────────── │
│ 信号拆解 Top3:                        │
│ ① 宫位权重 .38  ② 主星状态 .29       │
│ ③ 落宫路由 .21                       │
│ [点击宫位预览] [点击主星跳转]          │
└──────────────────────────────────────┘
```

### 颜色与状态

| 状态 | 分数 | 表现 |
|---|---:|---|
| 背景 | 0—20 | 深灰蓝，静态 |
| 轻度 | 21—40 | 浅色，弱呼吸 |
| 活跃 | 41—60 | 主色，稳定动画 |
| 高活跃 | 61—80 | 暖色强调，节点脉冲 |
| 密集 | 81—100 | 高对比强调，但不闪烁 |

## 3、卡片A：年宫轮值盘

### 目标

| 视觉元素 | 说明 |
|---|---|
| 12宫环 | 年龄轮转 |
| 当前宫 | 高亮 |

### 视觉示意

```text
┌──────────────────────────────────────┐
│ ┌───── 12宫轮值环 ──────────────┐    │

│ │   12宫    ● 年宫轮     8宫    │    │
│ │      1宫        7宫          │    │
│ │        2宫 ··· 6宫           │    │
│ └──────────────────────────────┘    │
│ ◄ 9宫(去年)  ▸ 11宫(明年)           │
│ ─────────────────────────────────── │
│ 年度关键词: 事业·位置·责任           │
│ [点击其他宫→预览该宫主题]            │
└──────────────────────────────────────┘
```

### 文字层

| 层级 | 内容 |
|---|---|
| 一句话摘要 | 今年是你的【第N宫】年份，年度主题聚焦【主题】。 |
| 展开解读 | 解释年宫的核心主题，并说明它是全年优先级，不是唯一会发生的事。 |

### 展开解读示例

> 今年进入第10宫年，事业、位置、责任和公开评价成为主线。你会更在意自己是否站在合适的位置。

- 一阶段：点击“展开详细解读”显示90—140字解释。
- 二阶段：点击图表中的节点、时间段或领域，与轮盘或对应专题页联动。

### 数据来源

- 年龄、出生上升、宫位轮转规则。
